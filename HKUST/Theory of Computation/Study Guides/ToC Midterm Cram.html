0. The one question behind the whole course

Every language in this course is a set of strings. The only thing that matters is: how much memory does a machine need to check whether a string belongs?

The classes are nested: every regular language is also context-free (a PDA can ignore its stack), so "even number of $a$s" is both. The table lists each example under the smallest class that can handle it, because "is it regular?" on the exam means "can it be done with no stack?". Rule of thumb: even / odd / mod $k$ / contains a pattern needs finite memory (regular); exactly equal / more than / twice as many needs an unbounded count (a stack, so context-free but not regular); two independent counts or comparing with a copy needs more (not context-free).

Every midterm question is one of: build the tool for a language, say which class a language is in and prove it, or say whether combining languages keeps you in a class. That is all.

1. Strings and languages

  • An alphabet is the set of letters allowed. Written $\Sigma$. Example $\Sigma=\{a,b\}$.
  • A string is letters in a row: $a$, $ab$, $abba$. The string with no letters is written $e$. Its length is 0.
  • $\Sigma^*$ means "every string you can make", including $e$.
  • A language is any set of strings. Examples: $\{ab, abb\}$ (two strings), "all strings with an even number of $a$s" (infinitely many), $\emptyset$ (no strings at all), $\{e\}$ (one string, the empty one). $\emptyset$ and $\{e\}$ are different.
  • Gluing languages: $L_1L_2$ = take any string of $L_1$ then any string of $L_2$. $L^*$ = glue zero or more strings of $L$ together ($e$ always included). $L^+$ = one or more.
  • $w^R$ = $w$ written backwards. $|w|_a$ = number of $a$s in $w$.
Exam use: the questions describe languages in words like "$w$ has twice as many $b$s as $a$s" or with set notation like $\{a^ib^j : i\le 2j\}$, which reads "some $a$s then some $b$s, where the number of $a$s is at most twice the number of $b$s".

2. Regular expressions: recipes for strings

A regex is a formula that describes a language. Only three building moves:
SymbolRead it asExample
$\alpha\beta$ (side by side)"$\alpha$ then $\beta$"$ab$ = the string $ab$

$\alpha^*$"$\alpha$ repeated 0 or more times"$a^*$ = $e, a, aa, aaa,\dots$
Special: $\emptyset$ is the recipe that produces nothing. $\emptyset^*$ produces exactly $e$. You may not write $e$ or $+$ inside a regex in this course. Write $\emptyset^*$ for $e$ and $aa^*$ for "one or more $a$".

How to read one: $(a\cup b)^*a$ = "any letters, any number of them, then an $a$" = strings ending in $a$.
How to write one: say the language in words using only "then", "or", "repeat", then translate. "Contains $aba$" = "anything, then $aba$, then anything" = $(a\cup b)^*aba(a\cup b)^*$.

Midterm 2013 Q2: binary numbers 0 to 11 = $\{0,1,10,11,100,101,110,111,1000,1001,1010,1011\}$. Group by length: one digit $0\cup1$; two digits $1(0\cup1)$; three digits $1(0\cup1)(0\cup1)$; four digits must start $10$: $10(0\cup1)(0\cup1)$. Join with $\cup$. Lesson: a finite language is just the "or" of its strings, so every finite language is regular.

3. DFA: a machine with no notebook

A DFA is a drawing of circles (states) and arrows (transitions). You put your finger on the start circle (the one with an arrow coming from nowhere), read the string one letter at a time, and follow the arrow with that letter. When the string ends, if your finger is on a double circle (final state), the answer is yes.

The rule that makes it a DFA: every circle has exactly one arrow for each letter. So there is never a choice and never a dead end. If some letter should lead nowhere useful, draw a "dead" circle that loops to itself on everything and is not final.

The key idea: the circle you are standing in is the machine's entire memory. So to design a DFA you ask: what is the small piece of information I need to remember while reading? One circle per possible value of that information.
LanguageWhat to rememberCircles
even number of $a$sis the count so far even or odd2

even $a$s AND odd $b$sboth parities at once$2\times2=4$
Midterm 2012 Q1a, "contains $aba$", step by step:
  1. Circles: $q_e$ (matched nothing yet), $q_a$ (last letter was $a$), $q_{ab}$ (last two were $ab$), $q_{aba}$ (found it). Start $q_e$. Final $q_{aba}$.
  2. Forward arrows spell the pattern: $q_e\xrightarrow{a}q_a\xrightarrow{b}q_{ab}\xrightarrow{a}q_{aba}$.
  3. Other arrows: ask "after this letter, what is the longest tail of what I read that is a beginning of $aba$?" $q_e$ on $b$: nothing, stay. $q_a$ on $a$: the last letter is still $a$, stay in $q_a$. $q_{ab}$ on $b$: $abb$ ends with nothing useful, back to $q_e$. $q_{aba}$: found, loop on both letters.
  4. Count: 4 circles times 2 letters = 8 arrows. Check with $abab$ (yes) and $abb$ (no).
Q1b "does not contain $aba$": same drawing, swap which circles are double. This works because a DFA has exactly one path per string. (Never do this to an NFA.)

Midterm 2011 Q1, "even 0s and odd 1s": run two tiny machines at once. Circles are pairs (parity of 0s, parity of 1s). Start (even, even). Reading 0 flips the first part, reading 1 flips the second. Final: (even, odd). This "pairs of states" trick is called the product construction and handles any "and" or "or" of two conditions.

Writing the answer: the drawing is enough and preferred. Add one line saying what each circle means, which is the start, which are final.

4. NFA: the machine that may guess

An NFA is the same drawing but the strictness is gone: a circle can have two arrows for the same letter, or none, and it can have arrows labelled $e$ that you may follow without reading a letter. A string is accepted if there exists at least one way of choosing arrows that ends in a final circle with the whole string read. If a branch has no arrow for the next letter, that branch just dies.

Think of it as the machine guessing. "Ends with $aba$": the machine reads letters in a loop, at some point guesses "the last three start now", and then checks $a$, $b$, $a$. If the guess was right, that branch accepts.
Midterm 2012 Q1c: $q_0$ with loops on $a$ and $b$; $q_0\xrightarrow{a}q_1\xrightarrow{b}q_2\xrightarrow{a}q_3$; $q_3$ final. Note $q_0$ has two arrows on $a$ (stay or go to $q_1$): that is the guess.

Why NFAs matter: they make "or", "then", "repeat" easy to draw (that is how a regex becomes a machine), and any NFA can be turned into a DFA, so guessing adds no power.

Turning an NFA into a DFA (subset construction), midterm 2012 Q1d: a DFA circle will be "the set of NFA circles I could be in right now". Start with $\{q_0\}$. For each letter, look at every circle in the set, collect everything reachable with that letter, then also add anything reachable by $e$-arrows. Each new set is a new row.
Seton $a$on $b$final?

Regex to NFA, the three gluing pictures: "or": new start with $e$-arrows into both machines. "Then": $e$-arrows from the finals of the first into the start of the second. "Repeat": a new start circle that is also final, $e$-arrow into the old start, $e$-arrows from the old finals back to the new start. Midterm 2012 Q2 asked why you need a new start circle for "repeat" instead of just making the old start final. Answer: if the old start has arrows coming into it, making it final accepts strings that merely return there mid-way. Example machine for $a(ba)^*$: $s\xrightarrow{a}f$, $f\xrightarrow{b}s$. Making $s$ final accepts $ab$, which is not in $(a(ba)^*)^*$ because every non-empty string there ends in $a$. The wrong construction always accepts everything it should, plus extra, so $L(M')\supseteq L^*$.

5. Lego rule for regular languages

If $A$ and $B$ are regular, then so are: $A\cup B$, $AB$, $A^*$, $\overline A$ (everything not in $A$), $A\cap B$, $A-B$, $A^R$ (reverse every string). Why: regex gives union, then, repeat; a DFA with finals swapped gives complement; pairs of states give intersection; and $A-B=A\cap\overline B$.

This is used two ways on the exam:
  • Show something is regular without drawing it: "numbers divisible by 2 or 3" = (divisible by 2) $\cup$ (divisible by 3), each is a small DFA, so the union is regular.
  • Prove a property is preserved (midterm 2011 Q6, $A^R$ regular, 20 pts): go through the regex cases. Reverse of $\emptyset$ is $\emptyset$, of a letter is the letter, of "$\alpha$ or $\beta$" is "$\alpha^R$ or $\beta^R$", of "$\alpha$ then $\beta$" is "$\beta^R$ then $\alpha^R$" (order flips), of "$\alpha$ repeated" is "$\alpha^R$ repeated". That is a complete proof by induction on the regex. Same pattern works for Pref (all beginnings of strings) and Subseq.

6. Proving a language is NOT regular

The idea in a story. A DFA with $n$ circles reading a string of $n$ or more letters must step on some circle twice within the first $n$ letters (there are more steps than circles). The letters read between the two visits form a loop. The machine cannot tell whether you went round that loop once, twice, or zero times. So if $w$ is accepted, so is $w$ with that loop repeated or removed.

The theorem says exactly this: if $L$ is regular, there is a number $n$ such that every $w\in L$ with $|w|\ge n$ can be cut as $w=xyz$ where $y$ is not empty, $xy$ is within the first $n$ letters, and $xy^iz\in L$ for every $i\ge0$ ($y$ repeated $i$ times).

How to use it to prove NOT regular: assume $L$ is regular, pick one clever long string in $L$, show that no matter where the loop $y$ is, repeating or deleting it leaves $L$. That contradicts the theorem.
The clever string: make its first $n$ letters all the same, so that $y$ is forced to be some number of that letter. Then count.

Midterm 2011 Q5, "twice as many $b$s as $a$s", full answer: 
Suppose L is regular, and let n be the pumping constant.
Let w = a^n b^(2n). Then w ∈ L and |w| ≥ n.
Write w = xyz with y ≠ e, |xy| ≤ n. Because |xy| ≤ n, xy is inside the a's, so y = a^k for some k ≥ 1.
Take i = 0: xz = a^(n-k) b^(2n). It has n-k a's and 2n b's, and 2(n-k) ≠ 2n since k ≥ 1.
So xz ∉ L, contradicting the pumping theorem. Hence L is not regular.
Midterm 2012 Q4c, "more $a$s than $b$s": pick $w=b^na^{n+1}$ ($b$s first on purpose). $y=b^k$. Repeat it: $i=2$ gives $b^{n+k}a^{n+1}$, now $b$s $\ge$ $a$s, not in $L$. If you had put $a$s first, repeating $a$s keeps you in $L$ and you would have to delete instead.
Midterm 2013 Q4, $\{x\bar x\}$ (a string followed by its bit-flip): shortcut. If $L$ were regular, then $L\cap L(0^*1^*)$ would be regular (Lego rule). But a string of the form "0s then 1s" that is $x\bar x$ must be $0^n1^n$. And $\{0^n1^n\}$ is not regular (the textbook pumping: $w=0^n1^n$, $y=0^k$, $i=0$). Contradiction. This "intersect with a simple regex to land on $a^nb^n$" trick is often the fastest.

7. Grammars: rules that build strings

A grammar is a list of rewrite rules. Capital letters are placeholders. Start with $S$. Pick any capital in your current string and replace it using one of its rules. Stop when no capitals remain. Every string you can reach this way is in the language.
Example $S\to aSb\mid e$ (the bar means "or"): $S\Rightarrow aSb\Rightarrow aaSbb\Rightarrow aabb$. The language is $\{a^nb^n\}$. Notice this needs counting, which a DFA cannot do, so grammars are more powerful than regex.

How to design a grammar: give every capital a meaning in words, then write rules that keep the meaning true.
  • $E$ = "equal number of $a$s and $b$s". Rules: $E\to e$ (empty is equal). If the string starts with $a$, walk until the count of $a$s minus $b$s first returns to zero; that position is a $b$. Between them is an equal string, after it is an equal string: $E\to aEbE$. Symmetric: $E\to bEaE$.
  • Midterm 2012 Q4a, "more $a$s than $b$s": $S$ = "more $a$s". Walk until the count first reaches $+1$: before that is an equal string $E$, then the letter $a$, then the rest has count $\ge0$, so it is either equal ($E$) or more ($S$): $S\to EaE\mid EaS$.
  • $T$ = "$a^mb^n$ with $m\ge n$": extra $a$s in front then a matched part: $T\to aT\mid U$, $U\to aUb\mid e$.
  • Midterm 2011 Q2, even-length strings that are not palindromes: think of matching letters from the outside in. Outer pairs match for a while ($S\to 0S0\mid1S1$), then one pair mismatches ($S\to 0A1\mid 1A0$), then anything of even length inside ($A\to 0A0\mid0A1\mid1A0\mid1A1\mid e$).
Writing the answer: list the rules, say what each capital means, derive one example string.

Regular languages are also context-free (midterm 2013 Q5): turn a regex into a grammar case by case. Letter $\sigma$: $S\to\sigma$. "$\alpha$ or $\beta$": $S\to S_\alpha\mid S_\beta$. "$\alpha$ then $\beta$": $S\to S_\alpha S_\beta$. "$\alpha$ repeated": $S\to e\mid SS_\alpha$. Use different capital names for the two sub-grammars so they do not interfere.

8. PDA: an NFA with a stack of plates

A PDA is an NFA plus a stack. Each arrow is labelled letter, pop $\to$ push: "reading this letter, if this is on top of the stack, remove it and put that instead". Any part can be $e$ (read nothing, pop nothing, push nothing). A string is accepted if some branch finishes reading it in a final state with an empty stack. Both conditions.

Running one by hand uses triples (state, unread input, stack with top on the left). For $\{a^nb^n\}$ with arrows $s$: $a,e\to a$ (push an $a$ for each $a$); $s\to f$ on $e,e\to e$ (switch phase); $f$: $b,a\to e$ (pop an $a$ for each $b$):
$(s,aabb,e)\vdash(s,abb,a)\vdash(s,bb,aa)\vdash(f,bb,aa)\vdash(f,b,a)\vdash(f,e,e)$ accept.

The design recipe: phase 1 pushes while reading the first part, an $e$-move switches phase (that move is a guess if the middle is not marked), phase 2 pops while reading the second part. The stack must be empty at the end, which is what forces the counts to match.

The counter trick (for "same number", "more", "twice as many"): first push a bottom marker $c$ (so you can tell the stack is otherwise empty). The stack always holds only the surplus letter. Reading $a$: if a $b$ is on top, pop it (they cancel); otherwise push $a$. Reading $b$: mirror. At the end, pop $c$ to accept. For "more $a$s than $b$s" (midterm 2012 Q4b), instead of popping $c$ directly, first require an $a$ on top (pop it and move to a cleanup state), then pop the remaining $a$s and $c$ with $e$-moves. For $\{a^ib^j : i\le2j\}$, each $b$ may pop zero, one, or two $a$s (three arrows); the empty-stack rule forces all $a$s to be gone.

Writing the answer: the drawing with labels, a line "in state $q$ the stack holds ...", and one traced example.

9. Grammar and PDA are the same thing

Grammar to PDA: push $S$. Whenever a capital is on top, replace it (pop it, push the right side of one of its rules; this is the guess). Whenever a small letter is on top, it must equal the next input letter; pop it and read the letter. The stack always shows the part of the derivation still to come. Only two states: $p$ (push $S$) and $q$ (everything else, final).
PDA to grammar: make a capital $A_{pq}$ for every pair of states, meaning "strings that take the machine from $p$ to $q$ starting and ending with an empty stack". Three rule shapes: $A_{pq}\to aA_{rs}b$ when the first push (at $p\to r$ reading $a$) is popped by the last move (at $s\to q$ reading $b$); $A_{pq}\to A_{pr}A_{rq}$ when the stack empties in the middle at $r$; $A_{pp}\to e$. You will be asked to state these, not to run them on a big machine.

10. Lego rule for context-free languages

If $A$ and $B$ are CF, then $A\cup B$, $AB$, $A^*$ are CF (glue the grammars: $S\to S_A\mid S_B$, $S\to S_AS_B$, $S\to e\mid SS_A$). Also $A\cap R$ is CF when $R$ is regular (run the PDA and the DFA together as pairs of states). But $A\cap B$ and $\overline A$ need not be CF: $\{a^nb^nc^m\}\cap\{a^mb^nc^n\}=\{a^nb^nc^n\}$, which is not CF.

How to answer true/false closure questions (midterm 2013 Q3, 35 points): for each statement ask "can I build the result using only allowed operations?" If yes, write "true, by closure under ...". If the statement claims something is NOT in a class, it is almost always false: try $A=\emptyset$, $A=\Sigma^*$, or $B=\overline A$. The full list with answers is in the closure table below.
Midterm 2011 Q4: the complement of $\{a^nb^nc^n\}$ IS context-free, even though the language itself is not. The complement = (strings not shaped $a^*b^*c^*$, which is regular) $\cup$ ($a^ib^jc^k$ with $i\ne j$, CF) $\cup$ ($a^ib^jc^k$ with $j\ne k$, CF). Union of CF pieces is CF.

11. Proving a language is NOT context-free

Same story as for regular, but the repeatable part comes in two pieces $v$ and $y$ around a middle $x$ (because a tall parse tree repeats a capital, and that capital has stuff on both sides). The theorem: there is $N$ such that any $w\in L$ with $|w|\ge N$ can be cut as $uvxyz$ with $v$ and $y$ not both empty, $|vxy|\le N$, and $uv^ixy^iz\in L$ for all $i$.
Use: pick $w=a^Nb^Nc^N$. Because $vxy$ is short, it touches at most two of the three blocks. Repeating $v$ and $y$ grows at most two blocks, so the third no longer matches. Contradiction. Shortcut: intersect with $a^*b^*c^*$ to land on $\{a^nb^nc^n\}$, which is known not CF.

12. Countable or uncountable

A set is countable if you can line its elements up in a queue where everyone gets served after a finite wait. Anything made of finite strings over a finite alphabet is countable: list by length, then alphabetically. So every language is countable, all regexes, all grammars, all machines, pairs of numbers, finite sets of numbers.
"All subsets of an infinite set" and "all infinite 0/1 sequences" are uncountable. Why (diagonal trick): suppose someone hands you the queue $A_0,A_1,A_2,\dots$ of all subsets of $\mathbb N$. Build $D$ = the numbers $i$ that are not in $A_i$. $D$ disagrees with $A_i$ about the number $i$, for every $i$, so $D$ is not in the queue. But $D$ is a subset. The queue was incomplete.
Midterm 2011 Q3: pairs $(x,y)$ with $x\ne y$: countable. Any infinite language: countable. All languages: uncountable. All finite languages: countable. Midterm 2012 Q3b (find the flaw): someone runs the diagonal trick on the queue of all finite languages and gets $D$. The flaw: $D$ is not finite, so "$D$ should be in the queue" is simply false, no contradiction.
Why this matters: there are uncountably many languages but only countably many regexes, grammars, programs. So most languages have no description at all.

13. "Define a new machine" questions

The exam likes to change the storage (a queue instead of a stack, or accepting without emptying the stack) and ask you to write the formal definition and build an example. Everything stays identical except the storage line. Snapshot = (state, unread input, storage). One step = there is an arrow $((p,a,\beta),(q,\gamma))$ with the next input letter $a$ and the storage updated by removing $\beta$ and adding $\gamma$. For a stack both happen at the top: storage $\beta\eta$ becomes $\gamma\eta$. For a queue you remove at the front and add at the back: $\beta\eta$ becomes $\eta\gamma$. Accept: $(s,w,e)\vdash^*(f,e,e)$.
Midterm 2012 Q5b: a queue accepts $a^nb^ma^nb^m$ because it gives back the first half in the same order; a stack would give it reversed. Store the first $a^n b^m$, guess the middle, then match. Midterm 2011 Q7: accept by final state only versus final state plus empty stack; the conversions are in the L10 template.

14. Why this is actually easy

There are only three ideas. (1) Classify by memory: none, one stack, more. (2) Every machine has the same four-line definition with one slot changed. (3) Closure is Lego. Everything else is a template you fill in: build, classify and prove, or combine. The exam is open book and the same languages come back every year: $a^nb^n$, palindromes, equal counts, more $a$s than $b$s, $a^nb^nc^n$, $ww$. Learn those six and you have most of the counterexamples and most of the proofs.

Reference. L1. Sets, relations, functions

Definitions
  • $A \subseteq B$: every element of $A$ is in $B$. $A = B$ iff $A \subseteq B$ and $B \subseteq A$. This is how you prove set equality: both inclusions.
  • Power set $2^A$ = set of all subsets. $|2^A| = 2^{|A|}$. $2^{\{c,d\}} = \{\emptyset,\{c\},\{d\},\{c,d\}\}$.
  • Partition: non-empty, pairwise disjoint subsets whose union is $A$.
  • $A \times B$ = ordered pairs. A binary relation is any subset of $A \times B$.
  • Reflexive, symmetric, transitive. All three = equivalence relation, splits $A$ into equivalence classes.
  • Function $f: A \to B$: a relation with exactly one pair per element of $A$. Injective (one-to-one): different inputs give different outputs. Surjective (onto): every $b$ is hit. Bijection: both.
Traps $\emptyset \in \emptyset$ is false. $\emptyset \subseteq \emptyset$ is true. $\{a,b\} \subseteq \{a,b,\{a,b\}\}$ true, and $\{a,b\} \in \{a,b,\{a,b\}\}$ also true. $\{a\} \ne a$.

L2. Languages and regular expressions

Analogy A language is just a set of accepted passwords. A regular expression is a recipe that generates every valid password: $\cup$ means "pick one of", concatenation means "then", $*$ means "repeat zero or more times". Think of $\emptyset$ as a recipe that produces nothing, and $\emptyset^*$ as "repeat nothing zero times", which produces exactly the empty password $e$.
Words and languages
  • Alphabet $\Sigma$: finite set of symbols. Word: finite sequence. $|w|$ = length. Empty word $e$, $|e|=0$, $e \notin \Sigma$.
  • Concatenation $wu$, associative, $ew = we = w$. Reversal: $e^R = e$, $(au)^R = u^R a$. Theorem $(uw)^R = w^R u^R$ by induction on $|u|$. This is the model proof for the course.
  • Language: any $L \subseteq \Sigma^*$. $\emptyset \ne \{e\}$.
  • $L_1L_2 = \{xy : x\in L_1, y \in L_2\}$. $L^0=\{e\}$, $L^{n+1}=L^nL$. $L^* = L^0 \cup L^1 \cup \cdots$ (so $e \in L^*$ always). $L^+ = LL^*$, and $e \in L^+$ iff $e \in L$.
Edge cases to memorize $\{e\}^{1000} = \{e\}$. $L\emptyset = \emptyset$. $\emptyset^* = \{e\}$. $L^n \subseteq L^{n+1}$ is not true in general (only if $e \in L$), but $L^n \subseteq L^*$ always. $L^+ = L^*$ iff $e \in L$.
Regular expressions (inductive definition)
  1. $\emptyset$ and each $\sigma \in \Sigma$ are R.E.s.
  2. If $\alpha, \beta$ are R.E.s, so are $(\alpha\beta)$, $(\alpha \cup \beta)$, $\alpha^*$.
  3. Nothing else.
$L(\emptyset)=\emptyset$, $L(\sigma)=\{\sigma\}$, $L(\alpha\beta)=L(\alpha)L(\beta)$, $L(\alpha\cup\beta)=L(\alpha)\cup L(\beta)$, $L(\alpha^*)=L(\alpha)^*$. Precedence: $*$ then concatenation then $\cup$.
$e$ is not an R.E. Write $\emptyset^*$ for $\{e\}$. $\{e,a,aa\}$ is $\emptyset^* \cup a \cup aa$. There is no $+$ operator in this course.
A language is regular iff it equals $L(\alpha)$ for some R.E. $\alpha$. Every finite language is regular.

L3. Countability

Analogy A set is countable if you can put its elements in a queue where everyone eventually gets served (finite waiting time). Finite strings can be queued (shortest first). Infinite objects like "all subsets of $\mathbb{N}$" cannot: whatever queue you propose, the diagonal trick builds a subset that disagrees with person number $i$ on item $i$, so it is nowhere in the queue. Exam shortcut: anything made of finite strings over a finite alphabet is countable; anything that is "all subsets" or "all infinite sequences" of an infinite set is uncountable.
Definitions
  • Equinumerous: a bijection exists. Countably infinite: equinumerous with $\mathbb{N}$. Countable = finite or countably infinite. Otherwise uncountable.
  • Fact: $A$ is countably infinite iff its elements can be listed $a_0, a_1, a_2, \dots$ with every element at some finite position.
  • Pigeonhole (finite sets): $|A| > |B|$ means no injection $A \to B$.

$2^{\mathbb{N}}$ uncountable: suppose a list $A_0, A_1, \dots$ of all subsets. Let $D = \{i : i \notin A_i\}$. $D$ is a subset of $\mathbb{N}$ so $D = A_k$ for some $k$. Then $k \in D \iff k \notin A_k = D$. Contradiction.
$[0,1]$ uncountable: list $x_i = 0.d_{i0}d_{i1}\dots$; build $x$ whose $i$-th digit is $0$ if $d_{ii}\ne 0$, else $1$. $x$ differs from every $x_i$.
First major theorem Any finite representation (R.E., program, grammar) is a finite string over a finite alphabet, so there are only countably many representations. There are uncountably many languages ($2^{\Sigma^*}$). So some languages have no finite representation in any system: non-regular languages and unsolvable problems exist. This proves existence only.
Try it (Quiz 2): which is uncountable for countably infinite $A$: finite unions of countable sets, $A\times A$, or functions $A\to\{0,1\}$?
Functions $A\to\{0,1\}$. Each such function is a subset of $A$ (its preimage of 1), so this set is $2^A$, uncountable. The others stay countable.
Try it (HW1): prove the set of finite subsets of $\mathbb{N}$ is countable
Let $F_k$ = subsets of $\{0,\dots,k\}$; each $F_k$ is finite (size $2^{k+1}$). Every finite subset lies in some $F_k$, so the set is $\bigcup_k F_k$, a countable union of finite sets, hence countable. Alternative: encode each finite subset as a finite binary string over $\{0,1\}$; $\{0,1\}^*$ is countable.
Why it mattersCountability is the reason there exist problems no program can solve: there are more problems than programs. It returns in the halting problem and in every undecidability proof later in the course.

L4. Deterministic finite automata

Analogy A DFA is a person with no notebook reading a ticker tape one symbol at a time. All they can remember is which "mood" (state) they are in, and the moods are fixed in advance. Each symbol forces exactly one mood change. At the end, you check if the mood is a happy one (final). Because there is no notebook, a DFA cannot count arbitrarily high: it can tell "even or odd number of $b$s" (two moods) but not "same number of $a$s as $b$s" (infinitely many moods needed).
Definition (write it verbatim) $M = (K, \Sigma, \delta, s, F)$: finite set of states $K$, alphabet $\Sigma$, transition function $\delta: K\times\Sigma \to K$ (total: exactly one move per state and symbol), initial state $s\in K$, final states $F\subseteq K$.
Configuration $(q, w)$ = current state, unread input. $(q,\sigma w') \vdash_M (q', w')$ iff $\delta(q,\sigma)=q'$. $\vdash_M^*$ = zero or more steps.
$M$ accepts $w$ iff $(s,w)\vdash_M^*(q,e)$ with $q\in F$. $L(M)$ = set of accepted strings.
Design patterns
  • Parity / mod k: state = remainder so far. Even $b$s: 2 states, $b$ toggles, $a$ self-loops. Decimal divisible by 3: 3 states for digit sum mod 3; digits 0,3,6,9 self-loop, 1,4,7 advance by 1, 2,5,8 advance by 2.
  • Substring search: one state per prefix of the pattern already matched (like Ctrl-F). Forward edges spell the pattern; other edges fall back to the longest prefix of the pattern that is a suffix of what was read. Final state loops on everything.
  • Sink / dead state: a non-final state that loops on all symbols; needed to keep $\delta$ total when you want to reject.
  • Totality check: every state must have exactly one outgoing edge per symbol. Count them.
Closure via DFAs
  • Complement: swap final and non-final states: $(K,\Sigma,\delta,s,K-F)$. Works only for a DFA (one run per string). Do not do this to an NFA.
  • Intersection (product): $K_1\times K_2$, $\delta((p,q),\sigma) = (\delta_1(p,\sigma),\delta_2(q,\sigma))$, start $(s_1,s_2)$, finals $F_1\times F_2$. Run both machines in parallel.
  • Union: same product, finals $(F_1\times K_2)\cup(K_1\times F_2)$. Only the final-state set differs from intersection.
  • Concatenation and star are awkward with DFAs (where to split?) which motivates NFAs.

L5. Nondeterministic finite automata

Analogy An NFA is the same tape reader but with a superpower: it can clone itself whenever there is a choice, and it can also move "for free" ($e$-transitions). The string is accepted if at least one clone ends happy. Clones with no legal move just die (the branch is stuck). NFAs are not a real machine; they are a way to specify a language by guessing ("guess where the last three symbols start"). The subset construction shows the guessing adds no power, only convenience.
Definition $M = (K, \Sigma, \Delta, s, F)$ with transition relation $\Delta \subseteq K\times(\Sigma\cup\{e\})\times K$. The only difference from a DFA is $\Delta$ (a relation) versus $\delta$ (a function). Every DFA is an NFA.
$(q,w)\vdash_M(q',w')$ iff $w = uw'$ for some $u\in\Sigma\cup\{e\}$ with $(q,u,q')\in\Delta$.
$w$ is accepted iff some computation $(s,w)\vdash_M^*(q,e)$ has $q\in F$. Rejected only if every branch fails or gets stuck.
Where NFAs shine
  • "ends with $aba$": $q_0$ loops on $a,b$; $q_0\xrightarrow{a}q_1\xrightarrow{b}q_2\xrightarrow{a}q_3$, $F=\{q_3\}$. Four states, no fallback edges. The NFA guesses when the final $aba$ begins.
  • $(ab\cup aba)^*$: 3 states as an NFA, 5 as a DFA (with trap).
  • Union: new start with $e$-edges to both machines. Concatenation: $e$-edges from finals of the first to the start of the second.
  • Reversal: reverse every edge, swap start and final roles. If several finals, add a new start with $e$-edges into the old finals. Old start becomes the unique final.
Exam trap Do not complement an NFA by swapping finals. A string can have one accepting and one rejecting branch; after the swap it is still accepted. Convert to a DFA first.
Try it: NFA for $abba^* \cup a(ab\cup ba)^*bb$ (HW1)
New start $s$ with $e$-edges to two chains. Chain 1: $s_1\xrightarrow{a}\xrightarrow{b}\xrightarrow{b}\xrightarrow{a}f_1$ with $f_1$ looping on $a$. Chain 2: $s_2\xrightarrow{a}p$; from $p$ a loop reading $ab$ and a loop reading $ba$ (two intermediate states), then $p\xrightarrow{b}\xrightarrow{b}f_2$. $F=\{f_1,f_2\}$. L6. DFA = NFA = Regular expression

Fundamental theorem For any $L\subseteq\Sigma^*$ these are equivalent: some DFA accepts $L$; some NFA accepts $L$; some R.E. represents $L$. Proof cycle: R.E. $\to$ NFA $\to$ DFA $\to$ R.E. (DFA $\to$ NFA is trivial.)
Use: to show a language is regular you may give whichever of the three is easiest. To show it is not regular, show no R.E. (equivalently no DFA) exists.

R.E. $\to$ NFA (structural induction)

  • $\emptyset$: one non-final state, no edges. $\sigma$: two states, one $\sigma$-edge.
  • $\alpha\cup\beta$: new start, $e$-edges to $s_1$ and $s_2$; finals $F_1\cup F_2$.
  • $\alpha\beta$: $e$-edges from every final of $M_1$ to $s_2$; start $s_1$; finals $F_2$ only.
  • $\alpha^*$: new start state $s$, which is also final; $e$-edge $s\to s_1$; $e$-edges from every final back to $s$.
Why a NEW start state for star (asked on the 2012 midterm, 15 pts) Suppose instead you make the old start $s_1$ final and add $e$-edges from finals to $s_1$. Counterexample: $M$ for $a(ba)^*$ with $s_1\xrightarrow{a}f$, $f\xrightarrow{b}s_1$, $F=\{f\}$. With $s_1$ final, $ab$ is accepted ($s_1\to f\to s_1$) but $ab\notin L^*$ (every string in $L^*$ ends with $a$ or is $e$). In general the wrong construction accepts a superset of $L^*$: every string of $L^*$ is still accepted, plus junk that re-enters $s_1$ mid-word. The problem is edges that come back into $s_1$.

NFA $\to$ DFA (subset construction)

$E(q)$ = set of states reachable from $q$ by $e$-moves alone ($q\in E(q)$).
DFA states are subsets of $K$. Start $E(s)$. $\delta'(Q,\sigma) = \bigcup_{q\in Q}\{E(p) : (q,\sigma,p)\in\Delta\}$: take all $\sigma$-moves from any state in $Q$, then $e$-close. Finals: subsets containing some state of $F$. $\emptyset$ is the dead state. Build only reachable subsets.
Worked (2012 midterm 1d): "ends with $aba$" NFA: $q_0$ loops on $a,b$; $q_0\xrightarrow{a}q_1\xrightarrow{b}q_2\xrightarrow{a}q_3$.

DFA $\to$ R.E. (the $R(i,j,k)$ method)

Number states $q_1,\dots,q_n$ with $s=q_1$. $R(i,j,k)$ = strings that drive $M$ from $q_i$ to $q_j$ passing only through intermediate states numbered $\le k$ (endpoints exempt).
$L(M) = \bigcup\{R(1,j,n) : q_j\in F\}$.
$R(i,j,k) = R(i,j,k-1)\ \cup\ R(i,k,k-1)\,R(k,k,k-1)^*\,R(k,j,k-1)$: either avoid $q_k$, or go to $q_k$, loop at $q_k$ any number of times, leave $q_k$.
Basis $R(i,j,0)$: direct edge labels, plus $e$ (written $\emptyset^*$) if $i=j$. Induction on $k$ uses only $\cup$, concatenation, $*$, so every $R(i,j,k)$ has an R.E.
Practical tip for the exam For small machines, do not expand the recurrence blindly. Eliminate states one at a time: for each state $q$ to remove, for every pair (in-edge $\alpha$ from $p$, out-edge $\gamma$ to $r$) with self-loop $\beta$ on $q$, add edge $p\to r$ labelled $\alpha\beta^*\gamma$. That is the same recurrence written as a diagram.
Try it: triangle DFA, $a$ self-loops everywhere, $b$-edges $q_1\to q_2\to q_3\to q_1$, $F=\{q_2\}$. What language, what R.E.?
Strings whose number of $b$s is $\equiv 1 \pmod 3$. R.E.: $a^*ba^*(ba^*ba^*ba^*)^*$. Expanding $R(1,2,3)$ gives an uglier but equivalent expression.
Why it mattersThis equivalence is the reason you can type a regex and a tool like grep compiles it to a fast automaton behind the scenes.

L7. Closure properties of regular languages

Theorem Regular languages are closed under union, concatenation, Kleene star (via R.E.s or NFAs), complementation (DFA, swap finals), intersection (De Morgan: $L_1\cap L_2 = \overline{\overline{L_1}\cup\overline{L_2}}$, or product DFA), reversal (reverse the NFA, or structural induction on the R.E.), difference ($A - B = A\cap\overline{B}$), symmetric difference.
Analogy Closure properties are Lego rules: if you build a regular language out of regular bricks using only allowed operations, the result is still regular. On the exam this cuts two ways. To prove something IS regular, decompose it into simple regular pieces and glue. To prove something is NOT regular, show that gluing it with regular pieces would produce a known non-regular language, which is a contradiction.
Three ways to prove a language is regular
  1. Give an R.E.
  2. Give a DFA or NFA.
  3. Write it as a combination of known regular languages using closure operations.
Worked: decimal numbers divisible by 2 or 3. $L_1 = \{0\}\cup\{1..9\}\Sigma^*$ (no leading zeros, regular). $L_2 = L_1\cap\Sigma^*\{0,2,4,6,8\}$. $L_3 = L_1\cap L_4$ with $L_4$ the digit-sum mod 3 DFA. $L = L_2\cup L_3$ regular by closure.
Exam template: prove $L^R$ is regular (2011 midterm, 20 pts) By structural induction on the R.E. $\alpha$ with $L = L(\alpha)$, build $\alpha^R$: $\emptyset^R = \emptyset$, $\sigma^R = \sigma$, $(\alpha\cup\beta)^R = \alpha^R\cup\beta^R$, $(\alpha\beta)^R = \beta^R\alpha^R$, $(\alpha^*)^R = (\alpha^R)^*$. Then $L(\alpha^R) = L(\alpha)^R$ by induction, using $(uw)^R = w^Ru^R$. Alternative: NFA with edges reversed, new start with $e$-edges to old finals, old start becomes the only final.
Exam template: Pref, Subseq, and similar (Tutorials 1 and 4) Same pattern: define the operation on each R.E. case and check the language equation. $\mathrm{Pref}(\emptyset)=\emptyset$; $\mathrm{Pref}(\sigma) = \emptyset^*\cup\sigma$; $\mathrm{Pref}(L_1\cup L_2)=\mathrm{Pref}(L_1)\cup\mathrm{Pref}(L_2)$; $\mathrm{Pref}(L_1L_2) = \mathrm{Pref}(L_1)\cup L_1\mathrm{Pref}(L_2)$; $\mathrm{Pref}(L_1^*) = L_1^*\mathrm{Pref}(L_1)$. Automaton version: make every state that can reach a final state final. For $\mathrm{Subseq}(L)$: add an $e$-edge parallel to every edge of the NFA (skip any symbol).
Try it (Tutorial 4): true or false? (a) every subset of a regular language is regular; (b) $L$ regular implies $\{xy : x\in L, y\notin L\}$ regular; (c) $\{w : w = w^R\}$ regular; (d) $L$ regular implies $\{w\in L : w^R\in L\}$ regular.
(a) False: $\{a^nb^n\}\subseteq\{a,b\}^*$. (b) True: it is $L\overline{L}$, concatenation of two regular languages. (c) False: palindromes are not regular (pump $a^nba^n$). (d) True: it is $L\cap L^R$.

L8. Proving non-regularity: the pumping theorem

Analogy A DFA with $n$ states reading a string longer than $n$ must revisit a state (pigeonhole: $n+1$ visits into $n$ rooms). The piece of input between the two visits is a loop you can cut out or replay any number of times, and the machine cannot tell. So every long accepted string has a "replayable" chunk near its start. If you can find a long string in $L$ where every possible chunk, replayed, leaves $L$, the language cannot be regular.
Think of a bouncer who only remembers a mood. If they let in $a^nb^n$, there is some loop of $a$s they cannot count, so they also let in $a^{n+k}b^n$.
Pumping theorem (write exactly this) Let $L$ be regular. Then there is $n\ge1$ such that every $w\in L$ with $|w|\ge n$ can be written $w = xyz$ with (1) $y\ne e$, (2) $|xy|\le n$, (3) $xy^iz\in L$ for all $i\ge0$.
Quantifiers: $\exists n\ \forall w\ \exists x,y,z\ \forall i$. The negation you must prove: $\forall n\ \exists w\ \forall$ splits $\exists i$ with $xy^iz\notin L$.
Proof template (copy this structure in the exam)
  1. Suppose $L$ is regular. Let $n$ be the constant from the pumping theorem.
  2. Choose one specific $w\in L$ with $|w|\ge n$. Make the first $n$ symbols all the same letter so that $|xy|\le n$ pins $y$ inside one block.
  3. Consider any split $w = xyz$ with $y\ne e$, $|xy|\le n$. So $y = a^k$ for some $k\ge1$ (say why).
  4. Pick one $i$ (usually $0$ or $2$) and show $xy^iz\notin L$ by counting.
  5. This contradicts the pumping theorem. So $L$ is not regular.
Points are lost for: choosing $w$ that depends on the split, forgetting $y\ne e$, not using $|xy|\le n$, or only treating one split.
Worked examples (all appeared on past midterms or tutorials)
  • $\{a^ib^i\}$: $w=a^nb^n$, $y=a^k$, $i=0$: $a^{n-k}b^n\notin L$.
  • Twice as many $b$s as $a$s (2011, 20 pts): $w = a^nb^{2n}$, $y=a^k$, $i=0$ gives $a^{n-k}b^{2n}$, and $2(n-k)\ne 2n$.
  • More $a$s than $b$s (2012, 15 pts): $w = b^na^{n+1}$. $y = b^k$, $i=2$: $b^{n+k}a^{n+1}$ has at least as many $b$s as $a$s. Choosing $b$s first matters: with $w=a^{n+1}b^n$ pumping up keeps you in $L$; you would need $i=0$ and care about $k$.
  • $\{a^ib^j : i>j\ge1\}$: $w=a^{n+1}b^n$, $y=a^k$, $i=0$: $a^{n+1-k}b^n$ with $n+1-k\le n$.
  • $\{ww\}$: $w=a^nba^nb$, $y=a^k$ in the first block, $i=0$ or $2$ breaks the halves.
  • $\{x\bar{x}\}$ with $\bar{x}$ the bit-flip (2013, 20 pts): easier by closure. $L\cap L(0^*1^*) = \{0^n1^n\}$, which is not regular, so $L$ is not regular. If you pump directly: $w=0^n1^n$, $y=0^k$, $i=0$.
  • $\{a^i : i \text{ prime}\}$: $w=a^p$, $p\ge n$ prime, $y=a^q$, pump to $i=p+1$: length $p+pq = p(1+q)$, composite.
  • Palindromes: $w=a^nba^n$, $y=a^k$, $i=2$.
  • $\{(bab)^i(babbab)^i\}$: $w=(bab)^n(babbab)^n$, $|xy|\le n$ puts $y$ inside the first $(bab)^n$ block; pumping changes its length by $k$ which breaks the count or the pattern.
The closure shortcut (often cleaner) To show $L$ not regular: find a regular $R$ such that $L\cap R$ (or $h(L)$, $L^R$, etc.) equals a known non-regular language. If $L$ were regular, closure would make the result regular, contradiction. Example: $L$ = equal number of $a$s and $b$s. $L\cap L(a^*b^*) = \{a^nb^n\}$. Done.
Limits The pumping theorem is necessary, not sufficient. Satisfying it does not prove regularity. It can never be used to show a language IS regular.
Try it: is $\{w\in\{0,1\}^* : \#01 = \#10\}$ (number of $01$ substrings equals number of $10$ substrings) regular?
Yes. $\#01 = \#10$ iff $w$ starts and ends with the same symbol or $|w|\le1$. R.E.: $\emptyset^*\cup0\cup1\cup0(0\cup1)^*0\cup1(0\cup1)^*1$. Lesson: "needs counting" intuition is not a proof.
Why it mattersKnowing what regular languages cannot do tells you when a regex is the wrong tool, which is why "parse HTML with regex" is a famous mistake.

L9. Context-free grammars

Analogy A CFG is a set of rewrite rules for building sentences: start with $S$ ("sentence"), repeatedly replace a non-terminal by one of its allowed expansions, stop when only terminals remain. Each non-terminal is a "slot" with its own meaning. The trick for designing grammars is to name each non-terminal by the property of the strings it produces ($E$ = equal $a$s and $b$s, $A$ = one more $a$ than $b$) and then write rules that preserve that property.
Definition $G = (V,\Sigma,R,S)$: $V$ an alphabet of terminals and non-terminals, $\Sigma\subseteq V$ the terminals, $R\subseteq(V-\Sigma)\times V^*$ a finite set of rules (left side is a single non-terminal, that is what "context-free" means), $S\in V-\Sigma$ the start symbol. Write $A\to u$ for $(A,u)$.
$xAy\Rightarrow xuy$ if $A\to u$. $\Rightarrow^*$ = zero or more steps. $L(G) = \{w\in\Sigma^* : S\Rightarrow^* w\}$. A language is context-free if some CFG generates it.
Leftmost derivation: always expand the leftmost non-terminal. Parse tree: picture of a derivation; each parse tree has exactly one leftmost derivation. Ambiguous grammar: some string has two different parse trees. Inherently ambiguous language: every grammar for it is ambiguous, e.g. $\{a^ib^jc^k : i=j \text{ or } j=k\}$.

L10. Pushdown automata

Analogy A PDA is the NFA tape reader with one stack of plates. It can only see the top plate, push plates, or pop plates. That is enough to "remember" one unbounded count or to match nested things ($a$s with $b$s, brackets), because you push on the way in and pop on the way out. It is not enough to compare three things ($a^nb^nc^n$) or two separated copies ($ww$): once the plates are popped, the information is gone. Nondeterminism lets it guess, e.g. where the middle of $ww^R$ is.
Definition (write it verbatim) $M = (K,\Sigma,\Gamma,\Delta,s,F)$: states, input alphabet, stack alphabet, start, finals, and $\Delta$ a finite subset of $(K\times(\Sigma\cup\{e\})\times\Gamma^*)\times(K\times\Gamma^*)$.
Transition $((p,a,\beta),(q,\gamma))$: in state $p$, reading $a$ (or nothing if $a=e$), with $\beta$ on top of the stack, pop $\beta$, push $\gamma$, go to $q$. The leftmost symbol of a string is the top of the stack. Diagram label: $a,\beta\to\gamma$.
Configuration $(p,w,\beta)\in K\times\Sigma^*\times\Gamma^*$: state, unread input, stack (top on the left).
$(p,x,\alpha)\vdash_M(q,y,\zeta)$ iff there is $((p,a,\beta),(q,\gamma))\in\Delta$ with $x = ay$, $\alpha = \beta\eta$, $\zeta = \gamma\eta$ for some $\eta\in\Gamma^*$.
$M$ accepts $w$ iff $(s,w,e)\vdash_M^*(f,e,e)$ for some $f\in F$: input finished, final state, and empty stack. Nondeterministic by definition. Deterministic PDAs are strictly weaker (cannot do $\{ww^R\}$).
Four transition idioms
  • push: $((p,a,e),(q,\gamma))$. pop: $((p,a,\beta),(q,e))$.
  • push on top of a specific symbol: $((p,a,\beta),(q,\gamma\beta))$.
  • free state change: $((p,e,e),(q,e))$. Used to "guess the middle" or move to a cleanup phase.
  • bottom marker: first move $((s,e,e),(q,c))$ pushes $c$, last move $((q,e,c),(f,e))$ pops it. Lets you test "stack otherwise empty".

L11. PDA = CFG

Analogy A grammar is a recipe; a PDA is a cook with a to-do stack. CFG to PDA: put $S$ on the stack; whenever the top is a non-terminal, replace it by one of its rules (guess which); whenever the top is a terminal, it must match the next input symbol, so pop both. The stack always holds "the rest of the leftmost derivation still to be produced". PDA to CFG: a non-terminal $A_{pq}$ means "a string that takes the machine from $p$ to $q$ with an empty stack both times", and the rules describe how the first push is eventually popped.
Theorem 1: CFG $\to$ PDA (know the construction cold) Given $G=(V,\Sigma,R,S)$, let $M = (\{p,q\},\Sigma,V,\Delta,p,\{q\})$ with
  1. $((p,e,e),(q,S))$: push the start symbol.
  2. $((q,e,A),(q,x))$ for every rule $A\to x$: expand the top non-terminal.
  3. $((q,a,a),(q,e))$ for every $a\in\Sigma$: match a terminal with the input.
The stack content mimics a leftmost derivation. Example for $S\to SS\mid[S]\mid e$ on $[[\,]][\,]$: $(p,[[]][],e)\vdash(q,[[]][],S)\vdash(q,[[]][],SS)\vdash(q,[[]][],[S]S)\vdash(q,[]][],S]S)\vdash\cdots\vdash(q,e,e)$.
Theorem 2: PDA $\to$ CFG First make the PDA simple: one accepting state $q_{acc}$, and every transition either pushes exactly one symbol $((q,a,e),(p,t))$ or pops exactly one $((q,a,t),(p,e))$ (split bigger transitions through extra states; wrap with a bottom marker to get a single final state with empty stack).
Non-terminals $A_{pq}$ for all $p,q\in K$, start symbol $A_{q_0,q_{acc}}$. Rules:
  1. If $((p,a,e),(r,t))$ and $((s,b,t),(q,e))$ are transitions, add $A_{pq}\to aA_{rs}b$. (The symbol pushed first is popped last.)
  2. For all $p,q,r$: $A_{pq}\to A_{pr}A_{rq}$. (The first push was popped somewhere in the middle, at state $r$.)
  3. For all $p$: $A_{pp}\to e$.
Claim: $A_{pq}\Rightarrow^* w$ iff $w$ takes $M$ from $p$ with empty stack to $q$ with empty stack. Key observation: any such computation starts with a push and ends with a pop, and either that first symbol survives until the last step (rule 1) or it is popped earlier (rule 2).

L12. Closure properties of CFLs

Closed under
  • Union: rename non-terminals apart, add $S\to S_1\mid S_2$.
  • Concatenation: $S\to S_1S_2$.
  • Kleene star: $S\to e\mid SS_1$.
  • Intersection with a regular language: product of a PDA $M_1$ and a DFA $M_2$. States $K_1\times K_2$, stack from $M_1$, start $(s_1,s_2)$, finals $F_1\times F_2$. For each $((q_1,a,\beta),(p_1,\gamma))$ and every $q_2$: add $(((q_1,q_2),a,\beta),((p_1,\delta(q_2,a)),\gamma))$. For $e$-moves of $M_1$ the DFA component stays put. Build only reachable states.
  • Consequence: $L - R = L\cap\overline{R}$ is context-free when $L$ is CF and $R$ regular (Tutorial 6).
NOT closed under
  • Intersection: $\{a^nb^nc^m\}\cap\{a^mb^nc^n\} = \{a^nb^nc^n\}$, not CF. Both pieces are CF: $S\to TC, T\to aTb\mid e, C\to cC\mid e$ and $S\to AT, T\to bTc\mid e, A\to aA\mid e$.
  • Complement: if CFLs were closed under complement, then $L_1\cap L_2 = \overline{\overline{L_1}\cup\overline{L_2}}$ would make them closed under intersection. Contradiction.
  • Concrete (2011 midterm Q4): $\overline{\{a^nb^nc^n\}}$ IS context-free. It equals $\overline{L(a^*b^*c^*)}\ \cup\ \{a^ib^jc^k : i\ne j\}\ \cup\ \{a^ib^jc^k : j\ne k\}$: one regular piece and two CF pieces, union is CF. So complement of a non-CFL can be CF, which shows the class is not closed under complement.
Worked: is $L = \{w : |w|_a = |w|_b,\ w$ has neither $abaa$ nor $babb$ as substring$\}$ context-free? Yes. $L = L_1\cap R$ with $L_1$ = equal counts (CF) and $R$ = avoids the two substrings. $\overline{R} = L((a\cup b)^*(abaa\cup babb)(a\cup b)^*)$ is regular, so $R$ is regular, so $L$ is CF by the intersection theorem.
Try it (Tutorial 6): show $\{xx^Ryy^Rzz^R : x,y,z\in\{a,b\}^*\}$ and $\{a^ib^j : i\ne j\}$ are CF using closure
First is $PPP$ with $P=\{ww^R\}$ (CF), concatenation closure. Second is $\{a^ib^j:i>j\}\cup\{a^ib^j:i\lt j\}$, union of two CFLs ($S\to aS\mid aT$, $T\to aTb\mid e$ and the mirror).

L13. Pumping theorem for CFLs

Analogy A long string needs a tall parse tree, and a tall tree must reuse some non-terminal $A$ on one root-to-leaf path (pigeonhole on the finitely many non-terminals). The subtree under the upper $A$ yields $vxy$; the lower $A$ yields $x$. You can swap the small subtree for the big one (pumping up: $uv^2xy^2z$) or the big for the small (pumping down: $uxz$). Unlike the regular case, the pumped pieces come in pairs $v$ and $y$ around a middle $x$, which is why CFLs can match two things but not three.
Theorem (write exactly this) Let $L$ be context-free. Then there is $N\ge1$ such that every $w\in L$ with $|w|\ge N$ can be written $w = uvxyz$ with (1) $vy\ne e$, (2) $|vxy|\le N$, (3) $uv^ixy^iz\in L$ for all $i\ge0$.
Proof sketch: $b$ = max right-hand-side length (fanout), $N = b^{|V-\Sigma|+1}$. A parse tree with $\ge N$ leaves has height $\ge|V-\Sigma|+1$, so some path has a repeated non-terminal. Take the tree with fewest leaves and the lowest repeat so that $vy\ne e$ and $|vxy|\le N$.
Proof template
  1. Suppose $L$ is CF, let $N$ be the pumping constant.
  2. Choose $w\in L$, $|w|\ge N$, typically with blocks of length $N$ so that $|vxy|\le N$ means $vxy$ touches at most two adjacent blocks.
  3. Case on where $vxy$ sits. In each case pick $i$ ($0$ or $2$) and show the counts or the block order break.
  4. Also cover the case where $v$ or $y$ straddles two blocks: pumping then breaks the $a^*b^*c^*$ shape.
  5. Contradiction.
Worked
  • $\{a^ib^ic^i\}$: $w = a^Nb^Nc^N$. $vxy$ cannot contain both $a$s and $c$s. If it lies in one block, pumping changes one count. If it spans two blocks, pumping changes at most two of the three counts, or breaks the order. Either way $uv^2xy^2z\notin L$.
  • $\{a^nb^ma^nb^m\}$: $w = a^Nb^Na^Nb^N$. If $v$ or $y$ mixes letters, order breaks. Otherwise $v$ and $y$ sit in at most two adjacent blocks, so pumping changes one $a$-block without the other, or one $b$-block without the other.
  • $\{a^ib^ic^{2i}\}$ (Tutorial 6): same as the first with $w=a^Nb^Nc^{2N}$.
  • $\{a^ib^jc^k : j = \max(i,k)\}$ (Tutorial 6): $w=a^Nb^Nc^N$. $vxy$ in $a$s only: pump up, $i\gt j$. In $b$s only: pump up, $j\gt\max$. In $c$s only: pump up, $k\gt j$. Across $a$s and $b$s: pump down, then $j\lt k$. Across $b$s and $c$s: pump down, then $j\lt i$.
  • Equal numbers of $a$s, $b$s, $c$s: use closure. $L\cap L(a^*b^*c^*) = \{a^ib^ic^i\}$, not CF, so $L$ is not CF.
Which is which CF: $\{a^nb^n\}$, $\{ww^R\}$, $\{a^ib^jc^k : i+j=k\}$, palindromes, balanced brackets, equal $a$s and $b$s, $\{a^ib^j : i\ne j\}$, complement of $\{a^nb^nc^n\}$.
Not CF: $\{a^nb^nc^n\}$, $\{ww\}$, $\{a^nb^ma^nb^m\}$, $\{a^ib^ic^{2i}\}$, equal counts of three letters, $\{a^{n^2}\}$, $\{a^p : p$ prime$\}$.
Why it mattersLimits of context-free languages are why some languages need a type checker on top of the grammar, and why indentation-based syntax is tricky.

Decision guide: is it regular? Is it context-free?

  1. Finite? Regular (union of its words).
  2. Can a bounded memory decide it? Parity, mod $k$, "contains / ends with / avoids a substring", fixed-length lookback: regular. Write the DFA or R.E.
  3. Needs one unbounded counter or matching nested pairs? $\{a^nb^n\}$, palindromes, equal counts of two letters, balanced brackets, $i\le2j$: context-free, not regular. Write a CFG (name non-terminals by property) or a PDA (push then pop).
  4. Needs two counters, or comparing two separated copies? $\{a^nb^nc^n\}$, $\{ww\}$, $\{a^nb^ma^nb^m\}$: not even context-free.
  5. Built from known languages by closure? Regular ops: $\cup,\cdot,*,\cap,\overline{\ },-,R$. CF ops: $\cup,\cdot,*$, and $\cap$ with a regular language. CF is NOT closed under $\cap$ or complement.
  6. To prove NOT regular: pumping theorem with first $n$ symbols identical, or intersect with a regular language to reach $\{a^nb^n\}$.
  7. To prove NOT CF: CFL pumping with blocks of length $N$, or intersect with $a^*b^*c^*$ to reach $\{a^nb^nc^n\}$.

Q4 (12). Show $\overline{\{a^nb^nc^n\}}$ is context-free
$\overline L = \overline{L(a^*b^*c^*)}\cup\{a^ib^jc^k : i\ne j\}\cup\{a^ib^jc^k : j\ne k\}$.
First piece is the complement of a regular language, hence regular, hence CF. Second: $S\to XC$, $X\to aXb\mid aA\mid bB$, $A\to aA\mid e$, $B\to bB\mid e$, $C\to cC\mid e$ (generate $a^ib^j$ with $i\ne j$ then any $c$s). Third is symmetric with $a$s free in front. Q2 (15). Why "make $s$ final and add $e$ from $f$ to $s$" fails for Kleene star
(a) $M$: $s\xrightarrow{a}f$, $f\xrightarrow{b}s$, $F=\{f\}$, so $L=a(ba)^*$. In $M'$ the string $ab$ runs $s\to f\to s$ and $s$ is final, so $ab\in L(M')$, but $ab\notin L^*$ (every non-empty string of $L^*$ ends in $a$).
(b) ii: $L(M')\supseteq L^*$ always, sometimes strictly. Every concatenation of $L$-strings is accepted using the new $e$-edge, and $e$ is accepted since $s$ is final. The extra strings come from paths that re-enter $s$ through original edges and stop there.
Q3 (20). Finite languages are regular; find the flaw

languagea set of strings. Think "the list of accepted passwords". Can be infinite.

start state, final statewhere reading begins; the double circles where the answer is yes

Template 1: build a DFA

Steps. (1) Ask: what must I remember while reading? Make one state per possible memory value. (2) Mark the start (memory at the beginning). (3) For every state and every letter draw exactly one arrow. (4) Mark final the states where the memory means "yes". (5) Test on two strings: one in, one out.
Memory values by task. "even/odd number of $x$": 2 states. "number of $x$ mod $k$": $k$ states. "contains pattern $p$": one state per prefix of $p$ matched so far. "does not contain $p$": same, swap finals. Two conditions with and/or: product, states are pairs.
Write on paper.
States: ___ (meaning: ___). Start: ___. Final: ___ because ___. Transitions: [diagram]. Check: ___ is accepted, ___ is rejected.

Template 2: build an NFA, then convert to DFA

Steps. (1) Let the machine guess: a start state that loops on all letters, then a chain spelling the pattern. (2) For union, a new start with $e$-arrows into each piece. (3) For concatenation, $e$-arrows from the finals of the first piece to the start of the second. (4) For star, a new start that is also final, $e$ into the old start, $e$ from old finals back to the new start.
Convert. Table with rows = sets of NFA states reached so far. Start row $E(s)$. For each letter: collect all states reachable by that letter from any state in the row, then add $e$-closures. New sets become new rows. A row is final if it contains a final NFA state. Stop when no new sets appear.

Template 3: write a regex

Steps. Describe the strings in words with "then", "or", "repeat". Translate word for word. Check $e$: should the empty string be in? Check the all-one-letter strings.
Patterns. any string: $(a\cup b)^*$. contains $p$: $(a\cup b)^*p(a\cup b)^*$. ends with $p$: $(a\cup b)^*p$. even number of $a$s: $b^*(ab^*ab^*)^*$. no $aa$: $(b\cup ab)^*(a\cup\emptyset^*)$. finite set: union of the words. exactly $\{e\}$: $\emptyset^*$.

Template 4: write a CFG

Steps. (1) Give each nonterminal a meaning in words: "$S$ = strings with property P". (2) Ask how a string with P is built from smaller strings with P or with related properties. Write one rule per way. (3) Add the base case ($e$ or a single letter). (4) Derive one example string to check.
Shapes. Matching from outside in: $S\to aSb$. Free repetition: $A\to aA\mid e$. "Or": $S\to A\mid B$. "Then": $S\to AB$. Equal counts: $E\to e\mid aEbE\mid bEaE$. One extra: $S\to EaE\mid EaS$.

G = (V, Σ, R, S), V = {___}, Σ = {___}. Rules: ___. Meaning: S generates ___, A generates ___. Example derivation: S ⇒ ___ ⇒ ___ ⇒ w.

Template 5: build a PDA

Steps. (1) Decide what the stack counts or stores. (2) Phase 1: push while reading the first part. (3) An $e$-move to phase 2 (a guess if the middle is unknown). (4) Phase 2: pop while reading the second part, matching symbols. (5) Final state is the one you end in; stack must be empty, so if you used a bottom marker, pop it with an $e$-move at the end.
Counter trick. Push a bottom marker $c$. Stack holds only the surplus letter: reading $a$ with $b$ on top pops it, otherwise pushes $a$. Same for $b$. At the end pop $c$.

If yes: TRUE. If the statement claims something is NOT in a class, try $A=\emptyset$ or $A=\Sigma^*$ or $B=\overline A$: usually FALSE.

Mistakes that lose marks

  • DFA with a missing arrow or two arrows for one letter.
  • Complementing an NFA by swapping finals.
  • Choosing $w$ after seeing the split, or a $w$ whose first $n$ letters are mixed.
