ProbProbability Rules
Core Rules

Think of probability as measuring the "size" of events in the sample space (total = 1).

Addition
P(A∪B) = P(A)+P(B)−P(A∩B)
Complement
P(Aᶜ) = 1−P(A)
Intersection
P(A∩B) = P(A|B)·P(B)
Independence
P(A∩B) = P(A)·P(B)
Triple union trick
P(A∪B∪C) = 1−P(Aᶜ∩Bᶜ∩Cᶜ)
Always true
P(A∩B) ≤ P(A∪B)
💡 Triple Union — The Slickest Trick
P(at least one of A,B,C) = 1 − P(none of them happen)
If independent: = 1 − P(Aᶜ)·P(Bᶜ)·P(Cᶜ)
This shows up on every single exam. Always take the complement approach.
🎯 Past Exam — Oct 2024 Q14, Jan 2025 Q3
P(A)=0.4, P(B)=0.5, P(C)=0.3, mutually independent. Find P(A∪B∪C).
→ 1 − 0.6 × 0.5 × 0.7 = 1 − 0.21 = 0.79
⚠ Two Common Traps
Trap 1: P(A∪B|C) = P(A|C)+P(B|C) is only true when A and B are mutually exclusive (disjoint).
Trap 2: Independent ≠ Disjoint. If A and B are independent with P(A),P(B)>0, they are definitely NOT disjoint (and vice versa). They're completely different concepts.
Conditional Probability & Bayes

Intuition: P(A|B) = "Given B happened, what's the chance A also happened?" — you're narrowing the sample space to B.

Key Formulas
Conditional probability: P(A|B) = P(A∩B) / P(B)
Bayes' rule: P(A|B) = P(B|A)·P(A) / P(B)
Law of total probability: P(B) = P(B|A)·P(A) + P(B|Aᶜ)·P(Aᶜ)
🎯 Past Exam — Machines & Defects (appears in Oct 2024, Mar 2025, Jan 2025)
Machine A makes 60% of items (defect rate 2%), Machine B makes 40% (defect rate 5%).
P(defective)? Use law of total probability: 0.6×0.02 + 0.4×0.05 = 0.012+0.020 = 0.032
P(machine A | defective)? Bayes: P(D|A)·P(A)/P(D) = 0.02×0.6/0.1 = 0.12 (if P(D)=0.1 given)
Worked Example — Dice conditional
Roll 2 dice. P(sum = 7 | exactly one die shows 3)?
Solution — count the restricted space
Pairs where exactly one die is 3: (3,1),(3,2),(3,4),(3,5),(3,6),(1,3),(2,3),(4,3),(5,3),(6,3) = 10 outcomes
Of those, sum = 7: (3,4) and (4,3) = 2 outcomes
Answer: 2/10 = 1/5
Worked Example — Coins conditional
Toss fair coin 3 times. P(≥2 heads | ≥1 head)?
Solution
P(≥1 head) = 1 − P(all tails) = 1 − 1/8 = 7/8
P(≥2 heads) = P(HHT,HTH,THH,HHH) = 4/8
Note: if ≥2 heads, then automatically ≥1 head, so P(A∩B) = P(A) = 4/8
Answer: (4/8)/(7/8) = 4/7

Ch. 4Continuous Random Variables
PDF & CDF — the Basics

Key idea: For a continuous RV, you can't ask "what's the probability X equals exactly 5?" — that's always 0. Instead, you ask about intervals: "what's P(3 ≤ X ≤ 5)?" — and that's the area under the curve.

PDF → CDF
Integrate the PDF:
F(x) = ∫_{−∞}^{x} f(u) du

Probabilities = area under PDF:
P(a≤X≤b) = ∫_a^b f(x)dx
CDF → PDF
Differentiate the CDF:
f(x) = F'(x) = dF/dx

Always check: f(x) ≥ 0 and ∫f=1
Properties every valid PDF must satisfy
1. f(x) ≥ 0 everywhere
2. ∫_{−∞}^{∞} f(x) dx = 1 (use this to find unknown constant c!)
3. CDF is always: non-decreasing, right-continuous, F(−∞)=0, F(∞)=1
🎯 Past Exam — CDF properties (Oct 2024 Q3, Jan 2025 Q17, Mar 2025 Q6)
"Which is a property of any CDF?" → Answer is always "it is non-decreasing" or "right-continuous".
Wrong options that appear: "strictly increasing" (no — flat parts allowed), "always differentiable" (no — discrete RVs have jumps), "can decrease" (never).
Worked Example — Finding constant c
f(x) = ce^(−x) for x ≥ 0, zero otherwise. Find c.
Solution — set total area = 1
∫_0^∞ ce^(−x) dx = c·[−e^(−x)]_0^∞ = c·(0−(−1)) = c = 1
So c = 1. Then F(x) = 1 − e^(−x) for x ≥ 0.
Worked Example — Finding c with bounded range (Mar 2025 Q10)
f(x) = ce^(−x) for 1 < x < 2, zero otherwise. Find c.
Solution
∫_1^2 ce^(−x) dx = c·[−e^(−x)]_1^2 = c·(e^(−1) − e^(−2)) = 1
So c = 1/(e^(−1) − e^(−2)) = e²/(e−1)
Worked Example — Computing a probability
f(x) = x + 1/2 for 0 ≤ x ≤ 1. Find P(X > 1/3).
Solution
∫_{1/3}^1 (x + 1/2) dx = [x²/2 + x/2]_{1/3}^1 = (1/2 + 1/2) − (1/18 + 1/6) = 1 − 4/18 ≈ 0.78
Expected Value, Variance & LOTUS

Intuition: E(X) is the "average" value of X if you repeated the experiment many times. Variance measures how spread out the values are.

Formulas
E(X) = ∫_{−∞}^{∞} x · f(x) dx
E[g(X)] = ∫_{−∞}^{∞} g(x) · f(x) dx ← LOTUS (Law of the Unconscious Statistician)
Var(X) = E(X²) − [E(X)]²
E(aX+b) = a·E(X)+b     Var(aX+b) = a²·Var(X)
💡 LOTUS — The Big Shortcut
To find E[X²] or E[e^X] etc., you DON'T need to find the distribution of X² first. Just plug g(x) into the integral:
E[X²] = ∫ x² · f(x) dx — that's it.
🎯 Past Exam — E[X²] with LOTUS (Oct 2024 Q12, Mar 2025 Q8, Oct 2025 Q3) — appears EVERY exam
f(x) = 4x(1−x) on [0,1]. Find E[X²].
E[X²] = ∫_0^1 x² · 4x(1−x) dx = 4∫_0^1 (x³−x⁴) dx = 4·[x⁴/4 − x⁵/5]_0^1 = 4·(1/4 − 1/5) = 4/20 = 1/5

Wrong: (∫ x·f(x) dx)²    Wrong: ∫ x·(f(x))² dx    Correct: ∫ x²·f(x) dx
Worked Example — E(X) with power function
f(x) = 3x^(−4) for x > 1. Find E(X).
Solution
E(X) = ∫_1^∞ x · 3x^(−4) dx = 3 ∫_1^∞ x^(−3) dx = 3 · [−1/(2x²)]_1^∞ = 3 · (0 + 1/2) = 3/2 = 1.5
Worked Example — E[X³] with LOTUS (Jan 2025 Q14)
X ~ Uniform(0,2). Find E[X³].
Solution
f(x) = 1/2 on [0,2]. E[X³] = ∫_0^2 x³ · (1/2) dx = (1/2) · [x⁴/4]_0^2 = (1/2) · 4 = 2
Functions of Continuous RVs

Intuition: If Y = g(X), you want the distribution of Y. The method: work through the CDF of Y, then differentiate to get the PDF.

  1. Find the range of Y = g(X)
  2. Write F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y) — rearrange this in terms of X
  3. Express in terms of F_X or known integrals
  4. Differentiate to get f_Y(y) = F'_Y(y)
Worked Example — Y = √X, X ~ Uniform(0,1) (Jan 2025 Q24)
Find P(√X > 0.5).
Solution
P(√X > 0.5) = P(X > 0.25) = 1 − F_X(0.25) = 1 − 0.25 = 0.75
(Since X ~ Uniform(0,1), F_X(x) = x)
Worked Example — Y = e^X, X ~ Uniform(0,1)
Find CDF, PDF of Y, and E(Y).
Solution
Range of Y: since X ∈ [0,1], Y ∈ [1, e].
F_Y(y) = P(e^X ≤ y) = P(X ≤ ln y) = ln y    for 1 ≤ y ≤ e
f_Y(y) = d/dy(ln y) = 1/y
E(Y) = E[e^X] = ∫_0^1 e^x · 1 dx = e − 1 ≈ 1.718 (using LOTUS directly on X)
Uniform Distribution

Intuition: Everything equally likely. PDF is flat (constant). Useful as a building block.

X ~ Uniform(a, b)

PropertyFormula
PDFf(x) = 1/(b−a) for a < x < b, else 0
CDFF(x) = (x−a)/(b−a) for a ≤ x ≤ b
E(X)(a+b)/2
Var(X)(b−a)²/12
Exponential Distribution

Intuition: Models the waiting time until the next event (customer arrival, radioactive decay). The parameter λ is the rate — higher λ = faster arrivals = shorter average wait.

X ~ Exponential(λ), λ > 0

PropertyFormula
PDFf(x) = λe^(−λx) for x > 0
CDFF(x) = 1 − e^(−λx) for x ≥ 0
E(X)1/λ
Var(X)1/λ²
Memoryless Property
P(X > x+a | X > a) = P(X > x)
In plain English: If you've been waiting a minutes and no customer has arrived, the remaining wait time has the same distribution as if you just started. The past waiting time is "forgotten."

Proof: P(X>x+a|X>a) = P(X>x+a)/P(X>a) = e^(−λ(x+a))/e^(−λa) = e^(−λx) = P(X>x) ✓
Normal (Gaussian) Distribution

Intuition: The bell curve. By far the most important distribution — the CLT says averages of anything become normal for large n. Key skill: standardising to use Φ tables.

X ~ N(μ, σ²)

PropertyFormula
PDFf(x) = (1/σ√(2π)) · e^(−(x−μ)²/(2σ²))
Standard normalZ = (X−μ)/σ ~ N(0,1)
CDFΦ(x) — use table; no closed form
SymmetryΦ(−x) = 1 − Φ(x)
E(X)μ
Var(X)σ²
💡 The Standardisation Trick — used in almost every exam question
To find P(X < a) where X ~ N(μ, σ²):
1. Subtract μ, divide by σ: Z = (a − μ)/σ
2. Look up Φ(Z) in the table

P(X < a) = Φ((a−μ)/σ)     P(X > a) = 1 − Φ((a−μ)/σ)
🎯 Past Exam — P(X > 4), X ~ N(3,4) (Oct 2024 Q13, Mar 2025 Q9) — exact same question
X ~ N(3, 4), so μ=3, σ=√4=2. Find P(X > 4).
P(X > 4) = P(Z > (4−3)/2) = P(Z > 0.5) = 1 − Φ(0.5) = answer: 1 − Φ(0.5)
🎯 Past Exam — Normal probability with Φ expression (Oct 2025 Q10)
X ~ N(4, 4), so μ=4, σ=2. Find P(X > 2).
P(X > 2) = P(Z > (2−4)/2) = P(Z > −1) = 1 − Φ(−1) = Φ(1) [by symmetry]
Both "1−Φ(−1)" and "Φ(1)" are correct — they're equal by the symmetry rule.
Linear Transforms Stay Normal
If X ~ N(μ_X, σ²_X) and Y = aX + b, then:
Y ~ N(a·μ_X + b, a²·σ²_X)

Example (Oct 2025 Q6): X ~ N(2,1), Y = 2X−1.
E(Y) = 2·2−1 = 3. Var(Y) = 2²·1 = 4, so σ_Y = 2. → Y ~ N(3, 4), i.e. μ=3, σ=2
Sum of Independent Normals
If X ~ N(μ_X, σ²_X) and Y ~ N(μ_Y, σ²_Y) independent, and Z = X + Y − 2:
E(Z) = μ_X + μ_Y − 2    Var(Z) = σ²_X + σ²_Y    (variances always add for independent RVs)

Example (Jan 2025 Q9): X~N(3,1), Y~N(−3,2), Z=X+Y−2.
E(Z) = 3+(−3)−2 = −2. Var(Z) = 1+2 = 3. → Z ~ N(−2, 5) ← note σ² = σ²_X + σ²_Y, not σ
Ch. 7Limit Theorems
Sample Mean & WLLN

Setup: You take n independent, identically distributed (iid) samples X₁, …, Xₙ. The sample mean is X̄ₙ = (X₁+…+Xₙ)/n.

Properties of the Sample Mean
E(X̄ₙ) = μ     (it's an unbiased estimator for μ)
Var(X̄ₙ) = σ²/n     (variance shrinks as you take more samples)
Weak Law of Large Numbers (WLLN)
As n → ∞, X̄ₙ → μ in probability: lim P(|X̄ₙ − μ| ≥ ε) = 0

Plain English: The sample average converges to the true mean as you collect more data. This is why histograms with more data look more like the true distribution.
Central Limit Theorem (CLT)

Intuition: No matter what weird distribution your Xᵢ have, the average (or sum) of many of them becomes approximately normal. This is why the normal distribution is everywhere.

CLT — Two Equivalent Versions
For the average: X̄ₙ ~ N(μ, σ²/n) approximately for large n

For the sum Y = X₁+…+Xₙ: Y ~ N(nμ, nσ²) approximately

Standardised form: Z = (X̄ₙ − μ)/(σ/√n) ~ N(0,1) approximately
🎯 Past Exam — CLT on sum (Oct 2025 Q16)
X₁,…,X₁₀₀₀ iid, μ=0.4, σ²=1. Find P(X₁+…+X₁₀₀₀ ≤ 400).
Y = ΣXᵢ ~ N(1000×0.4, 1000×1) = N(400, 1000)
P(Y ≤ 400) = P(Z ≤ (400−400)/√1000) = P(Z ≤ 0) = Φ(0) = 0.5
🎯 Past Exam — CLT on Binomial (Jan 2025 Q4)
X ~ Binomial(20, 1/5). Approximate P(X > 8) using CLT.
μ = np = 4, σ² = np(1−p) = 20·(1/5)·(4/5) = 16/5
P(X>8) = P(Z > (8−4)/√(16/5)) = P(Z > 4/√(16/5)) = P(Z > 4·√5/4) = P(Z > √5) = 1 − Φ(√5)
Applying the CLT — Step by Step
  1. Identify X₁,…,Xₙ iid. Write down μ = E(Xᵢ) and σ² = Var(Xᵢ)
  2. Write Y = ΣXᵢ. Then Y ~ N(nμ, nσ²) approximately
  3. Standardise: Z = (Y − nμ)/(σ√n) ~ N(0,1)
  4. Convert the probability to Φ expressions
Worked Example — Bit errors
1000 bits, each has error probability 0.1. Find P(errors > 120).
Solution
Each Xᵢ ~ Bernoulli(0.1): μ=0.1, σ²=0.09. Total Y = ΣXᵢ ~ N(100, 90).
P(Y>120) = P(Z > (120−100)/√90) = P(Z > 20/9.49) = P(Z > 2.11) = 1 − Φ(2.11) ≈ 0.017
Worked Example — Finding required sample size (Jan 2025 Q11)
CI for a proportion with 90% confidence, 3% margin of error. Find n.
Solution
Margin = z_{0.05} · √(p̂(1−p̂)/n). Worst case: p̂=0.5 maximises p̂(1−p̂) = 0.25.
1.645 · √(0.25/n) ≤ 0.03 → √(0.25/n) ≤ 0.0182 → 0.25/n ≤ 0.000332 → n ≥ 752
→ Round up to n = 800 (nearest option)
Ch. 8Statistical Inference
Point Estimators

Setup: You observe data X₁,…,Xₙ from a distribution with unknown parameter θ. An estimator Θ̂ = h(X₁,…,Xₙ) is any function of your data used to guess θ.

Estimators are random variables themselves — they change with every new dataset.

Bias, MSE & Consistency
Bias
Bias(Θ̂) = E(Θ̂) − θ
If bias = 0 for all θ: unbiased. The estimator is "correct on average."
X̄ₙ is always unbiased for μ — this is a true/false exam favourite.
MSE — Bias-Variance Tradeoff
MSE(Θ̂) = E[(Θ̂ − θ)²] = Var(Θ̂) + [Bias(Θ̂)]²
Lower MSE = better estimator. If both are unbiased, compare by variance.
🎯 Past Exam — MSE true/false (Oct 2024 Q20, Jan 2025 Q1) — appears every exam
X₁,…,Xₙ ~ N(μ, 4). True or false:
• "Sample mean is unbiased for μ" → TRUE (always)
• "MSE equals 2/√n" → FALSE. MSE(X̄) = Var(X̄) = σ²/n = 4/n (not 4/√n, not 2/√n)
• "MSE equals 4/n" → TRUE
Consistent Estimator
Θ̂ₙ is consistent if it converges to the true θ as n → ∞: lim P(|Θ̂ₙ − θ| < ε) = 1
Shortcut: If MSE(Θ̂ₙ) → 0 as n → ∞, then it's consistent.
X̄ₙ is consistent for μ because Var(X̄ₙ) = σ²/n → 0.
🎯 Past Exam — Variance of sample mean (Oct 2024 Q19, Oct 2025 Q13)
X₁,…,Xₙ iid with Var(Xᵢ)=5. What is Var(X̄ₙ)?
Var(X̄ₙ) = σ²/n = 5/n
Wrong options that appear: 5/√n, 25/n, 10/n — they're always wrong. It's always σ²/n.
Sample Variance

Why n−1? When you don't know μ and estimate it with X̄, you lose one degree of freedom. Using n−1 instead of n corrects this so S² is unbiased.

Sample Variance S²
S² = 1/(n−1) · Σᵢ(Xᵢ − X̄)²
E(S²) = σ² — unbiased for σ²

Warning: S̄² = (1/n)·Σ(Xᵢ−X̄)² is biased: E(S̄²) = (n−1)/n · σ²
🎯 Past Exam — Computing S² by hand (Oct 2025 Q14)
x₁=−2, x₂=0, x₃=2. Compute S².
X̄ = (−2+0+2)/3 = 0
S² = 1/(3−1) · [(−2−0)² + (0−0)² + (2−0)²] = 1/2 · [4+0+4] = 8/2 = 4
Maximum Likelihood Estimation (MLE)

Intuition: Given your observed data, which value of θ makes the data most likely? That's the MLE.

Likelihood Function L(θ)
Discrete: L(θ) = P(X₁=x₁) · P(X₂=x₂) · … · P(Xₙ=xₙ)
Continuous: L(θ) = f(x₁;θ) · f(x₂;θ) · … · f(xₙ;θ)

Maximise L(θ) — equivalently maximise log L(θ) (easier, same answer)
  1. Write L(θ) as product of PMFs/PDFs evaluated at your data
  2. Take log: log L(θ) = Σ log f(xᵢ; θ)
  3. Differentiate w.r.t. θ and set = 0
  4. Solve for θ̂_ML
Worked Example — MLE for Exponential(λ)
Observations x₁,…,xₙ from Exp(λ). Find λ̂_ML.
Solution
L(λ) = λⁿe^(−λΣxᵢ) → log L = n·log λ − λ·Σxᵢ
d(log L)/dλ = n/λ − Σxᵢ = 0 → λ̂_ML = n/Σxᵢ = 1/x̄
Also: the likelihood L only depends on Σxᵢ, not the individual values → depends on the sum ✓
Worked Example — MLE for Geometric(θ) (Oct 2025 Q5)
x₁=3, x₂=2 from Geometric(θ). Find θ̂_ML.
Solution
L(θ) = P(X=3)·P(X=2) = θ(1−θ)² · θ(1−θ)¹ = θ²(1−θ)³
log L = 2 log θ + 3 log(1−θ)
d(log L)/dθ = 2/θ − 3/(1−θ) = 0 → 2(1−θ) = 3θ → 2 = 5θ → θ̂_ML = 2/5 = 0.4
Worked Example — MLE from given L(θ) (Jan 2025 Q23)
L(θ) = 12θ³(1−θ)⁵. Find θ̂_ML.
Solution
log L = log12 + 3 log θ + 5 log(1−θ)
d(log L)/dθ = 3/θ − 5/(1−θ) = 0 → 3(1−θ) = 5θ → 3 = 8θ → θ̂_ML = 3/8 = 0.375 ≈ 0.38
🎯 Past Exam — MLE true/false for Exponential (Oct 2024 Q21)
For Exp(λ) with observations x₁,…,xₙ:
• "Likelihood only depends on the sum Σxᵢ" → TRUE (L = λⁿe^(−λΣxᵢ))
• "MLE equals the sample mean" → FALSE. λ̂_ML = 1/x̄ (the rate), not x̄ itself
Confidence Intervals

Intuition: A single estimate like "μ ≈ 5.2" doesn't tell you how uncertain you are. A CI gives you a range like [4.1, 6.3] that captures the true μ with 95% probability across repeated experiments.

⚠ The Most Common Wrong Interpretation
WRONG: "There's a 95% chance μ is in [4.1, 6.3]." — μ is fixed, it's either in there or not.
CORRECT: "If we repeated this experiment many times, 95% of the computed intervals would contain the true μ." The interval is random, θ is not.
💡 The Pivot Method — How CIs are Built
1. Find a quantity Q(data, θ) whose distribution is known and doesn't depend on θ
2. Find qₗ, qₕ such that P(qₗ ≤ Q ≤ qₕ) = 1−α
3. Rearrange to isolate θ between two estimators

CI for the Mean — Which formula to use?

SituationPivot distributionCI formula
σ² known (any n) Z = (X̄−μ)/(σ/√n) ~ N(0,1) X̄ ± z_{α/2} · σ/√n
σ² unknown, large n Z ≈ (X̄−μ)/(S/√n) ~ N(0,1) by CLT X̄ ± z_{α/2} · S/√n
Normal pop., σ² unknown, small n T = (X̄−μ)/(S/√n) ~ t_{n−1} X̄ ± t_{α/2, n−1} · S/√n
Proportion p̂ = X̄, Bernoulli data Z ~ N(0,1) by CLT p̂ ± z_{α/2} · √(p̂(1−p̂)/n)
Key z-values to memorise (from formula sheet)
z_{0.005} = 2.58 → for 99% CI (α=0.01, use z_{α/2} = z_{0.005})
z_{0.025} = 1.96 → for 95% CI
z_{0.05} = 1.645 → for 90% CI
z_{0.1} = 1.28 → for 80% CI
💡 t-distribution — when and why
When n is small and σ is unknown, replacing σ with S introduces extra uncertainty. The t-distribution is like a "fatter" normal — wider tails. As n grows, t_{n−1} → N(0,1). Use t when the problem says "normally distributed" + small sample + σ unknown.
🎯 Past Exam — CI for proportion (Oct 2024 Q4, Mar 2025 Q4) — appears every exam
400 people, 240 prefer public transport. 99% CI for the proportion.
p̂ = 240/400 = 0.6. z_{0.005} = 2.58.
CI = 0.6 ± 2.58·√(0.6·0.4/400) = 0.6 ± 2.58·0.0245 = 0.6 ± 0.063 = [0.54, 0.66]
🎯 Past Exam — CI for mean, known σ (Oct 2025 Q1, Mar 2025 Q5)
x₁=2,x₂=3,x₃=1,x₄=2 from N(θ,1). 90% CI.
X̄ = 8/4 = 2. σ=1, n=4. z_{0.05}=1.645.
CI = 2 ± 1.645·(1/√4) = 2 ± 1.645·0.5 = 2 ± 0.82 = [1.18, 2.82]

• "CI becomes larger when sample size increases" → FALSE — larger n → smaller CI (σ/√n shrinks)
• "95% CI is smaller than 99% CI" → FALSE — 99% CI is wider (higher confidence = wider range)

CI for Variance σ² (needs normal population)

Pivot: (n−1)S²/σ² ~ χ²(n−1)

[(n−1)S² / χ²_{α/2, n−1} , (n−1)S² / χ²_{1−α/2, n−1}]

Note: χ²_{1−α/2, n−1} is the smaller value → goes in the denominator of the upper bound.

Hypothesis Testing

Intuition: You assume the null hypothesis H₀ is true, then check: is the data so surprising that it's hard to believe H₀? If yes, reject it.

Key Definitions
H₀ — null hypothesis (default, "nothing special")
H₁ — alternative hypothesis (what you're trying to show)
Test statistic W — a function of data, designed to detect deviations from H₀
Rejection region R — values of W so extreme we reject H₀
Significance level α — P(Type I error) ≤ α; you control this
Type I Error — α
Reject H₀ when H₀ is TRUE
"False alarm." You control this via α.
P(Type I) = P(W ∈ R | H₀ true) ≤ α
Type II Error — β
Fail to reject H₀ when H₁ is TRUE
"Missed detection." Harder to control.
Larger rejection region → smaller β
🎯 Past Exam — Type I vs Type II (Oct 2024 Q10, Mar 2025 Q13)
• "Type I error occurs when a true null hypothesis is rejected" → TRUE
• "Type II error occurs when a false null hypothesis is not rejected" → TRUE
• Car speed: H₀: μ≤50, H₁: μ>50, rejection region K=[55,∞). T=54 (not rejected), actual μ=52 (H₁ true). → Type II error

Test Statistic for the Mean

W = (X̄ − μ₀) / (σ/√n) [replace σ with S if unknown, large n] T = (X̄ − μ₀) / (S/√n) [t-test, small n, normal population]
Test typeH₀H₁Reject H₀ when
Two-sidedμ = μ₀μ ≠ μ₀|W| > z_{α/2}
Right-sidedμ ≤ μ₀μ > μ₀W > z_{α}
Left-sidedμ ≥ μ₀μ < μ₀W < −z_{α}
🎯 Past Exam — Computing Type I error probability (Oct 2024 Q24, Mar 2025 Q15)
X₁,…,X₉ ~ N(μ,1). H₀: μ=1. Reject H₀ if X̄ > 1.5. Find P(Type I error).
P(Type I) = P(X̄ > 1.5 | μ=1) = P(Z > (1.5−1)/(1/√9)) = P(Z > 0.5/0.333) = P(Z > 3/2)
= 1 − Φ(3/2)
🎯 Past Exam — Two-sided z-test (Oct 2024, Mar 2025 Q12)
X₁,…,X₄ ~ N(μ,1). Observed: 2.82, 2.71, 3.22, 2.67. Test H₀:μ=2 vs H₁:μ≠2, α=0.1.
X̄ = 2.855. W = (2.855−2)/(1/2) = 1.71. z_{0.05} = 1.645.
Since |1.71| > 1.645: Reject H₀
🎯 Past Exam — Right-sided test, large n (Oct 2024 Q18, Jan 2025 Q15)
X₁,…,X₃₆ ~ N(μ,36). X̄=24, σ=6. Test H₀:μ=25 vs H₁:μ<25 (left-sided). Find p-value.

💡 Which test to use?
Large n, any distribution, σ unknown → use S, z-test (CLT)
Small n, normal distribution, σ unknown → t-test with t_{n−1}
Small n, normal distribution, σ known → z-test
P-values

Intuition: The p-value answers: "If H₀ is true, how likely am I to see data as extreme as what I observed?" Very small p = data strongly contradicts H₀.

Definition & Decision Rule
p-value = smallest α for which you'd reject H₀ = P(seeing W this extreme | H₀ true)

Decision: If p-value < α → reject H₀. If p-value ≥ α → fail to reject H₀.

P-value formulas (W = observed test statistic)

Test typeP-value
Two-sidedp = 2·(1 − Φ(|w|))
Right-sided (H₁: μ > μ₀)p = 1 − Φ(w) = P(Z > w)
Left-sided (H₁: μ < μ₀)p = Φ(w) = P(Z < w)
🎯 Past Exam — P-value interpretation (Oct 2024 Q15, Mar 2025 Q14)
P-value = 0.04, α = 0.05. What do you conclude?
Since 0.04 < 0.05: Reject H₀.

Bonus: "If rejected at α=0.025, must it be rejected at α=0.05?" → YES (larger α means easier to reject)
"If rejected at α=0.025, must it be rejected at α=0.01?" → NO (maybe not, need smaller p-value)
🎯 Past Exam — Type II error facts (Jan 2025 Q21)
• "Type II error = not rejecting H₀ when H₀ is true" → FALSE (that's a correct decision!). Type II = not rejecting H₀ when H₁ is true.
• "If rejection region gets larger, P(Type II error) gets smaller" → TRUE — bigger R = more aggressive = fewer missed detections
