3. Linear Models

Linear Regression

ŷ = w·x + b     Loss = ½ Σ(ŷᵢ − yᵢ)²

The ½ exists so it cancels the 2 from the chain rule when differentiating. Predicts continuous values.

Logistic Regression

p = σ(w·x + b)     σ(z) = 1/(1+e⁻ᶻ)     Loss = cross-entropy

Binary classification. Output is a probability in (0,1). Equivalent to a 1-layer neural network with sigmoid activation. Points near the boundary weigh most heavily in the loss.

Why Square the Error (MSE)?

✓ Valid reasons

  • Prevents + and − errors from cancelling
  • Penalizes large errors more than small ones
  • Equivalent to MLE under Gaussian noise

✗ NOT a reason

  • "Points near the boundary weigh most heavily" — that describes log loss, not MSE

Decision Boundary

For a linear classifier: boundary = hyperplane where w·x + b = 0. Points on one side → positive class, other side → negative class.

Linear decision boundary: w points perpendicular to the boundary, toward the positive class

4. k-Nearest Neighbours (k-NN)

How it works

  1. Store all training data (no training phase)
  2. For new point: compute distance to all training points
  3. Find k nearest neighbours
  4. Majority vote (classification) or average (regression)

Properties

  • Lazy: all computation deferred to prediction
  • Non-parametric: no fixed model form
  • Small k → overfitting | Large k → underfitting
  • O(n) prediction time — slow for large n
  • Sensitive to irrelevant features → normalize first

k-NN with k=3: the query point (orange) finds its 3 nearest neighbours and predicts by majority vote

5. Support Vector Machines (SVMs)

SVMs find the hyperplane that maximizes the margin — the distance between the boundary and the nearest training points.

SVM: maximize the margin between classes. Support vectors (orange ring) are the points that define the margin.

Hard Margin SVM

No misclassifications allowed. Only works when data is linearly separable.

Soft Margin SVM (C)

Allow violations with penalty C. Large C → smaller margin, fewer violations. Small C → larger margin, more violations allowed.

Loss = ½||w||² + C·Σ max(0, 1 − yᵢ(w·xᵢ+b))

Kernel Trick

Replace dot products x·z with a kernel function k(x,z) = φ(x)·φ(z). This implicitly maps to a higher-dimensional space where data is linearly separable, without ever computing φ(x) explicitly. Enables non-linear boundaries.

6. Neural Networks

Why we need activations

Composing linear functions = still linear. f(g(x)) = A(Bx) = (AB)x — just another linear transformation. No matter how many layers you stack without activations, the network is equivalent to a single linear model.

Activation functions break this: ReLU(Wx + b) is non-linear. With enough hidden units and non-linear activations, an MLP is a universal approximator.

Multi-layer perceptron (MLP). Each layer applies: output = activation(W·input + b)

Backpropagation

Algorithm to compute gradients efficiently using the chain rule. Two passes:

Forward pass

Compute outputs layer by layer, store intermediate values (needed for gradients)

Backward pass

Propagate gradient from loss back through network using chain rule. Each layer computes: upstream_grad × local_derivative

The gradient points uphill (direction of steepest increase in loss). Gradient descent subtracts the gradient: θ ← θ − η∇L to go downhill.

7. Activations, Regularization & Batch Norm

Activation Functions

Sigmoid causes vanishing gradients in deep networks. ReLU avoids this.

L1 vs L2 Regularization — Deep Comparison

PropertyL1 (Lasso)L2 (Ridge)
PenaltyΣ|wᵢ|Σwᵢ²
Effect on weightsDrives to exactly 0 (sparsity)Shrinks toward 0, never reaches it
Why exact zeros?Subdifferential at w=0 includes [−1,+1]: if loss gradient < 1, update stops at 0Gradient = 2w → 0 as w→0, so force vanishes before reaching 0
GeometryDiamond-shaped constraint: solutions hit corners (= axes = sparse)Sphere-shaped constraint: solutions hit sphere surface (rarely on axis)
Use caseFeature selection — irrelevant features get weight = 0General overfitting prevention
SolutionSparse (many zeros)Small but non-zero everywhere

L1 constraint is a diamond — loss contours hit the corners (axes), creating sparse solutions. L2 is a sphere — solutions land on the smooth surface, rarely on axes.

Batch Normalization

Normalizes activations to approximately N(0,1) over the current mini-batch. Applied between layers. Stabilizes training, allows higher learning rates.

Batch norm normalizes to a normal (Gaussian) distribution, NOT uniform. It operates on the batch dimension, not the feature dimension.

Dropout

Randomly sets neuron outputs to 0 during training (probability p). Creates ensemble effect — each forward pass uses a different network topology. At test time, all neurons active (outputs scaled by 1−p). Reduces overfitting.

8. Convolutional Neural Networks (CNNs)

A convolutional layer = a fully connected layer with two constraints:
  1. Connections removed: each output unit connects only to a local region (receptive field)
  2. Weights shared: the same filter weights are applied at every spatial position

❌ NOT: limiting the L2 norm of weights. ❌ NOT: pooling operations.

CNN pipeline: input → convolve with filter (same weights everywhere) → feature map → pool → smaller feature map

OperationWhat it doesEffect on size
Convolution (stride=1, no pad)Apply filter at every positionShrinks slightly
PaddingAdd zeros around borderPreserves size
Stride=2Filter moves 2 pixels at a timeHalves spatial dimensions
Max pooling (2×2)Keep max in each 2×2 regionHalves spatial dimensions

9. Sequences: RNN vs LSTM vs Transformer

RNN

hₜ = f(hₜ₋₁, xₜ)

Sequential processing. Maintains hidden state. Problem: vanishing gradients — early tokens forgotten.

❌ Can't model long-range dependencies well

LSTM

Has cell state + forget gate + input gate + output gate

Forget gate decides what to keep from cell state. Cell state = "conveyor belt" — information can flow unchanged.

✓ Solves vanishing gradients ❌ Still sequential

Does NOT make Markov assumption.

Transformer

Self-attention: every token attends to every other token simultaneously.

Needs position embeddings (attention is order-invariant without them).

✓ Parallelizable ✓ Long-range direct ❌ Quadratic memory

LSTM cell: cell state (top) carries long-term memory through gates that control what to forget/remember/output

Sequence-to-Sequence layers

✓ Are sequence layers

1D Convolution, RNN, LSTM, Transformer

✗ NOT sequence layers

Gradient Boosting, Word2Vec, DQN, standard MLP (no sequential structure)

10. Generative Models

Autoencoder

Encoder: x → z (single point)

Decoder: z → x̂

Loss: reconstruction only ||x − x̂||²

Cannot generate new samples (unstructured latent space)

VAE

Encoder: x → (μ, σ) — a distribution

Sample: z = μ + σ·ε, ε~N(0,I)

Decoder: z → x̂

Loss: reconstruction + KL(q||N(0,I))

NO discriminator

GAN

Generator G: noise z → fake data

Discriminator D: real or fake?

Adversarial training (minimax game)

Mode collapse: G produces same few outputs

Has discriminator

VAE architecture: encoder outputs a distribution, we sample from it, decoder reconstructs. No discriminator.

GAN Variants

VariantKey featureUse case
Standard GANG + D adversarial gameUnconditional generation (e.g., faces)
Conditional GANBoth G and D receive conditioning signal y (e.g., class label)Paired input→output (sketch→photo, grayscale→color)
CycleGANTwo G's + two D's + cycle-consistency loss: G(F(x)) ≈ xUnpaired translation (horse→zebra without matched pairs)
StyleGANSeparates style and content in latent spaceHigh-quality face generation with style control
Conditional GAN requires PAIRED training examples. CycleGAN works with unpaired collections. Know this difference!

ELBO — Why VAEs can't maximize ln p(x) directly

L(q,θ) + KL(q,p) = ln p(x|θ) Since KL ≥ 0 always: L(q,θ) ≤ ln p(x|θ) → ELBO is a LOWER BOUND on the log-likelihood

Why we need it: ln p(x|θ) = ln ∫p(x,z|θ)dz — we'd need to integrate over all possible z. Intractable. ELBO is tractable and gives a lower bound we can optimize instead.

VAE loss (negated, since we minimize): −E_q[ln p(x|z)] + KL(q(z|x) || N(0,I))

  • First term = reconstruction loss (how well decoder reconstructs x)
  • Second term = KL regularizer (forces latent space to be structured like N(0,I))

11. Embeddings & Recommender Systems

Matrix Factorization

Decomposes user-item rating matrix R ≈ U × Vᵀ

Each user u → vector uᵤ, each item i → vector vᵢ

Predicted rating: r̂ᵤᵢ = uᵤ · vᵢ (dot product)

Cold start: new item/user has no interactions → no embedding can be learned

Word2Vec

Learns word embeddings from unlabeled text via co-occurrence

CBOW: predict word from context words

Skip-gram: predict context from word

Similar words → similar vectors (king − man + woman ≈ queen)

Both matrix factorization and Word2Vec learn embeddings for featureless objects — items/users/words that have no predefined feature vector. The embedding IS the learned representation.
Cold start = new item or user with NO historical interaction data. NOT about incomplete feature records. You can't learn an embedding without any interaction history.

Implicit vs Explicit Feedback

TypeExamplesProperties

ImplicitClicks, views, purchases, listening time, pausesAbundant, noisier, more representative

12. Reinforcement Learning

Policy Gradients (PG)

Network outputs probability distribution over actions π(a|s)

Directly optimizes policy by estimating gradient of expected reward

Deep Q-Network (DQN)

Network outputs Q-value for each action Q(s,a) = expected future reward

Learns a value function; policy = take action with highest Q-value

Why gradient descent is hard in RL: the step from model output → action → reward involves the environment, which is non-differentiable. Can't backpropagate through it directly.

14. Probability & Information Theory

Bayes' Rule

P(B|A) = P(A|B) × P(B) / P(A) For classification: P(class|data) ∝ P(data|class) × P(class)

Entropy & Cross-Entropy — Full picture

Entropy: H(p) = −Σ p(x) log₂ p(x) Cross-entropy: H(p,q) = −Σ p(x) log₂ q(x) ← p is TRUE, q goes in log KL divergence: KL(p||q) = H(p,q) − H(p) ≥ 0

Intuition: H(p) = minimum bits to encode a draw from p. H(p,q) = bits needed if you use a code optimized for q but data actually comes from p. KL = extra wasted bits.

THE critical cross-entropy trap

H(p,q) is UNDEFINED when q(x)=0 but p(x)>0

Reason: you'd need log₂(0) = −∞, making the term p(x)·(−∞) = +∞

H(p,q) IS defined (=0) when both p(x)=0 AND q(x)=0. By convention: 0·log(0) = 0.

Every recent exam includes one undefined cross-entropy. Check every position where q(x)=0.

Bias-Variance Decomposition

As model complexity increases: bias decreases, variance increases. Optimal at the sweet spot.

Bias and variance CANNOT be computed from a single model on a single dataset. You need multiple training datasets (or bootstrapping) to observe how much predictions vary.

Train / Validation / Test — Rules

  1. Train model on training set
  2. Tune hyperparameters using validation set (or cross-validation)
  3. Report final performance on test set ONCE — never use test set for decisions

Using test set multiple times inflates performance via the multiple testing problem.

Walk-forward validation: for time series data. Always train on past, validate on future. Never mix time periods.

Data leakage: computing normalization statistics (mean/std) on the full dataset including test data. Always compute on train set only, then apply to test.

APPLICATION QUESTION PROCEDURES

A. Ranking Errors & Coverage

Every exam Q26–28

  1. Compute score for each instance: s = w·x + b
  2. Rank instances from lowest score (most negative) to highest (most positive)
  3. Count ranking errors: a PAIR (pos, neg) where negative is ranked more positive than positive
  4. Coverage = ranking errors / (#pos × #neg)
⚠ Ranking error = PAIR, not misclassification. For each positive instance p, count how many negatives n are ranked above it (have higher score). Sum over all positives.

Worked Example

Classifier: score = 2x₁ − x₂. Instances:

Instancex₁x₂LabelScore
a34Pos2(3)−4 = 2
b15Pos2(1)−5 = −3
c26Neg2(2)−6 = −2
d41Neg2(4)−1 = 7

Ranking (neg to pos): b(−3), c(−2), a(2), d(7)

Positives: a, b. Negatives: c, d.

For b (Pos, score=−3): c(−2) > b(−3) ✗ = error; d(7) > b(−3) ✗ = error → 2 errors

For a (Pos, score=2): d(7) > a(2) ✗ = error → 1 error

Total: 3 ranking errors. Coverage = 3 / (2×2) = 3/4

B. Entropy & Cross-Entropy Computation

Every exam Q31–33

H(p) = −Σ p(x) log₂ p(x) [entropy of p] H(p,q) = −Σ p(x) log₂ q(x) [p is TRUE, q in log] KL(p||q) = H(p,q) − H(p) [always ≥ 0]

Step-by-step procedure

  1. Check for undefined first: is there any position where q(x)=0 but p(x)>0? If yes → H(p,q) = undefined. Stop.
  2. For each outcome x: compute −p(x)·log₂(q(x)) and sum
  3. Remember: 0·log(0) = 0 (when p(x)=0, the term is 0 regardless of q(x))

Worked Example

p = (1/2, 1/4, 1/8, 1/8), q = (1/4, 1/4, 1/4, 1/4)

H(p) = −(1/2)log₂(1/2) − (1/4)log₂(1/4) − (1/8)log₂(1/8) − (1/8)log₂(1/8)

= (1/2)(1) + (1/4)(2) + (1/8)(3) + (1/8)(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits

H(p,q): q is uniform, so log₂(1/4) = −2 for all terms:

= −(1/2)(−2) − (1/4)(−2) − (1/8)(−2) − (1/8)(−2) = 1+0.5+0.25+0.25 = 2.0 bits

KL(p||q) = 2.0 − 1.75 = 0.25 bits

D. Decision Tree — Information Gain

Every exam Q36–38

  1. For each feature, tally class distribution on both sides of the split
  2. Find the most uneven distribution → highest info gain (shortcut, no computation needed if obvious)
  3. To compute exact IG: IG = H(parent) − Σ (weight × H(child))

Worked Example

12 instances at a node. Feature x₁ split gives: left={5Y, 1N}, right={2Y, 4N}

H(parent, 7Y+5N of 12): −(7/12)log₂(7/12) − (5/12)log₂(5/12) ≈ 0.980 bits

H(left, 5Y+1N of 6): −(5/6)log₂(5/6) − (1/6)log₂(1/6) ≈ 0.650 bits

H(right, 2Y+4N of 6): −(2/6)log₂(2/6) − (4/6)log₂(4/6) = H(1/3,2/3) ≈ 0.918 bits

Weighted: (6/12)(0.650) + (6/12)(0.918) = 0.784 bits

IG = 0.980 − 0.784 = 0.196 bits

E. Naive Bayes — Spam/Ham Classification

Appears in recent exams Q33–35

P(class | x₁,...,xₙ) ∝ P(class) × P(x₁|class) × P(x₂|class) × ... × P(xₙ|class)
  1. Compute class priors: P(Spam) = #spam/#total
  2. Count conditional probs: P(feature=T|Spam) = #spam with feature T / #spam total
  3. Multiply scores: Score(Spam) = P(Spam)×P(f1|Spam)×P(f2|Spam)×...
  4. Argmax: predict class with higher score
  5. For exact probability: P(Spam|email) = Score(Spam)/(Score(Spam)+Score(Ham))

Laplace Smoothing

If any count is 0 → whole product = 0. Fix: add pseudo-observations.

Smoothed P(feature=T | class) = (count + 1) / (class_total + #feature_values) For binary feature: +1 numerator, +2 denominator Example: 3/4 → smoothed = (3+1)/(4+2) = 4/6
Do NOT simplify fractions before smoothing. 2/4 → 1/2 then +1/+2 = 2/4 ≠ (2+1)/(4+2) = 3/6. Keep the original counts.

F. Matrix Backpropagation

Recent exams Q39–40

Setup: y = xA where x is a 1×n row vector, A is n×m, y is 1×m row vector.

y_i = Σₖ A_{ki} x_k Scalar derivative: ∂y_i/∂x_j = A_{ji} Backward pass: x∇ = y∇ · Aᵀ

Why x∇ = y∇Aᵀ

The j-th component of x∇ is: x∇ⱼ = Σᵢ y∇ᵢ · (∂yᵢ/∂xⱼ) = Σᵢ y∇ᵢ · Aⱼᵢ = (y∇Aᵀ)ⱼ

Worked Example

x=[1,0,1], A=[[2,1],[0,1],[1,0]], y∇=[3,−1]

Aᵀ = [[2,0,1],[1,1,0]]

x∇ = [3,−1] · [[2,0,1],[1,1,0]] = [3·2+(−1)·1, 3·0+(−1)·1, 3·1+(−1)·0] = [5, −1, 3]

x∇ = y∇Aᵀ NOT y∇A. You must transpose A.

G. ELBO Fill-in-the-Blanks

Appears in some exams

L(q,θ) + KL(q,p) = ln p(x|θ) L(q,θ) = E_q [ln p(x,z|θ)/q(z|x)] ← the ELBO KL(q,p) = −E_q [ln p(z|x,θ)/q(z|x)] ← always ≥ 0 Therefore: L(q,θ) ≤ ln p(x|θ) [ELBO is lower bound]

VAE loss (minimized): −E_q[ln p(x|z)] + KL(q(z|x) || N(0,I))

The key fill-in for the 2026 exam: ⟨a⟩ = p(z,x|θ)p(x|θ), ⟨b⟩ = ln p(x|θ)
