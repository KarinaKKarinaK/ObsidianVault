§2 — Gradients & Linear Regression

Differentiation rules

RuleFormula
Constant∂c/∂x = 0
Exponent∂xⁿ/∂x = nxⁿ⁻¹
Constant factor∂(cf)/∂x = c·∂f/∂x
Sum∂(f+g)/∂x = ∂f/∂x + ∂g/∂x
Chain∂f(g(x))/∂x = (∂f/∂g)(∂g/∂x)

Gradient descent

θ_new = θ − η · ∇loss(θ) where η is the learning rate (hyperparameter). Gradient points uphill → subtract it to go downhill.

One GD step: compute gradient at current θ, multiply by η, subtract from θ.

Linear regression — OLS

Model: f(a) = sa + b Loss: loss(s,b) = ½ Σᵢ (saᵢ + b − hᵢ)² Gradient wrt s: Σᵢ (aᵢs + b − hᵢ)aᵢ Gradient wrt b: Σᵢ (aᵢs + b − hᵢ) Optimal parameters (set gradients = 0): s = (āh − ā·h̄) / (ā² − ā²) b = h̄ − s·ā

ā = mean of a, h̄ = mean of h, ā² = mean of a², āh = mean of aᵢhᵢ

Why squared error?

Summing raw residuals → positive and negative errors cancel. Squaring also emerges naturally from MLE under Gaussian noise assumption. Squaring penalizes large errors more than absolute value.

Why GD not always best?

For many loss functions (e.g. accuracy), the gradient is zero almost everywhere → GD makes no progress. Use a smooth differentiable loss (squared error, cross-entropy) instead.

§3 — Evaluation: ROC, Confusion Matrix, Ranking

Confusion matrix

Predicted PosPredicted Neg
True PosTPFN
True NegFPTN
Accuracy = (TP+TN)/total Precision = TP/(TP+FP) — of predicted pos, how many correct? Recall = TP/(TP+FN) — of all pos, how many found? TPR = TP/(TP+FN) — same as recall FPR = FP/(TN+FP) — of all neg, how many called pos? F1 = 2PR/(P+R)

⚠ Confusion matrix CANNOT compute AUC — needs a ranking classifier.

Ranking classifiers

Linear classifier → ranking: sort by distance to decision boundary. Most negative (furthest from boundary on negative side) → most positive.

Decision tree → ranking: group instances by leaf; assign P(pos) by relative frequency in that leaf; sort groups by P(pos).

Coverage matrix

Rows = Pos instances (y-axis, sorted most-positive at bottom) Columns = Neg instances (x-axis, sorted most-positive at left) Cell (pos,neg): GREEN if pos ranked higher (correct) RED if neg ranked higher (error) YELLOW if tied (0.5 error each) Ranking errors = #red + 0.5×#yellow

ROC curve: normalize coverage matrix axes. AUC = probability of correctly ranking a random (Pos, Neg) pair. Convex hull for optimal ensemble.

§4 — Naive Bayes & Entropy

Naive Bayes classifier

p̂(Y | X₁,…,Xₖ) ∝ p(X₁|Y) · p(X₂|Y) · … · p(Xₖ|Y) · p(Y) Estimate each factor from relative frequency: p(Xᵢ = v | Y = c) = count(Xᵢ=v, Y=c) / count(Y=c) p(Y = c) = count(Y=c) / n Classification: argmax_Y over unnormalized product. For actual probabilities: normalize (divide by sum over all classes).

Why "naive": assumes features are conditionally independent given the class. Almost always false, but often works well.

Zero-count problem: if p(Xᵢ|Y) = 0 for any feature, entire product = 0 (that class gets probability 0 even if other features strongly support it).

Smoothing (pseudo-observations): add one fake observation per (feature value, class) combination. Every probability becomes nonzero.

Entropy

H(X) = −Σₓ p(x) log₂ p(x) Properties: H = 0 for deterministic distribution H = log₂(n) for uniform over n outcomes (maximum) H(uniform 4) = 2 bits H increases with uncertainty

Cross-entropy & KL divergence

Cross-entropy: H(p,q) = −Σ p(x) log₂ q(x) — expected code length when using code q but true distribution is p — UNDEFINED if q(x)=0 for any x where p(x)>0 KL divergence: KL(p‖q) = H(p,q) − H(p) ≥ 0 — extra bits paid for using q instead of p — not symmetric: KL(p‖q) ≠ KL(q‖p)

§5 — SVMs & Scalar Backpropagation

Support Vector Machines

Decision function: f(x) = wᵀx + b Class = sign(f(x)) [positive → Pos, negative → Neg] Soft-margin training objective: minimize ½‖w‖ + C·Σᵢ pᵢ s.t. yᵢ(wᵀxᵢ + b) ≥ 1 − pᵢ, pᵢ ≥ 0 where yᵢ = +1 (Pos) or −1 (Neg) Support vectors: points where wᵀxᵢ + b = yᵢ (exactly on the margin)
ClaimTrue/False
SVMs learn non-linear functions via kernel trick✓ (but base model is linear)
SVM is unsupervised✗ — supervised
Soft margin allows gradient descent✓ — this is the advantage
Support vectors = closest points to boundary✓
Hard margin: can apply L1 regularization✗ — hard margin IS the regularization

Scalar Backpropagation

Forward pass: compute and STORE all intermediate values Backward pass: compute local derivative at each module, chain together Chain rule: ∂loss/∂w₁ = (∂loss/∂y)(∂y/∂h₁)(∂h₁/∂k₁)(∂k₁/∂w₁) Sigmoid derivative: σ'(k) = σ(k)(1 − σ(k)) ReLU derivative: r'(k) = 0 if k < 0, else 1 Multivariate chain rule (diamond in computation graph): ∂f/∂x = Σ_paths (product of local derivatives along path)

Exam tip: break the function into named modules first, draw the graph, then chain.

Common traps

  • Dropout disabled nodes only at training time (not test)
  • Perceptron = composition of linear functions = still linear → can't learn XOR
  • Non-linear separation → derive new features OR use non-linear activation
  • Loss ≠ evaluation metric: accuracy has gradient ≈ 0 everywhere → can't use as loss
  • Eager execution = dynamic graph (built each forward pass) — NOT static

§7 — Generative Models (VAE & GAN)

Comparison table

ModelStructureKey mechanismAvoids mode collapse?
AutoencoderEncoder → bottleneck → decoderPoint embeddingN/A
VAEEncoder → distribution → sample → decoderReparameterization trickVia encoder network
GANGenerator vs DiscriminatorAdversarial trainingVia discriminator

VAE — must-know facts

  • Encoder outputs a distribution (mean + variance), NOT a point
  • VAE does NOT include a discriminator
  • VAE avoids mode collapse via the encoder network
  • Loss = reconstruction + KL(encoder distribution, prior N(0,I))
  • ELBO = variational lower bound on log p(x)
  • Reparameterization: z = μ + σ·ε, ε~N(0,I) → allows gradient to flow

GAN — must-know facts

  • Discriminator solves mode collapse by training generator to cover all modes
  • Conditional GAN: generator conditioned on input → use for colorization, text-to-image
  • Use conditional GAN when generation must depend on an input condition

§8 — Markov Models & Tensor Backpropagation

Markov model classification

Goal: classify email "w₁ w₂ w₃ w₄" Bayes' rule: p(spam|E) ∝ p(E|spam) · p(spam) Chain rule: p(w₁,w₂,w₃,w₄|spam) = p(w₄|w₃,spam)·p(w₃|w₂,spam)·p(w₂|w₁,spam)·p(w₁|spam) First-order Markov assumption: depends only on PREVIOUS word. Estimating probabilities: p(won|you,spam) = count("you won" in spam) / count("you" in spam) p(w₁|spam) = count(w₁ in spam) / total words in spam

⚠ A strong prior can flip the classification! Always check: p(E|class)·p(class) for each class.

Tensor (Matrix) Backpropagation

Problem: full Jacobian ∂y/∂x for tensors is too large to store (it's a 3-tensor).

Solution: compute Jacobian-vector products directly — don't compute the full Jacobian.

Linear layer: y = Wx + b Given upstream gradient y∇ (same shape as y): b∇ = y∇ (gradient for b) x∇ = y∇ W (row vector times W) W∇ = (y∇)ᵀ xᵀ (outer product style) Exam answer: "compute upstream × local, don't compute full Jacobian"

§9 — Decision Trees & ELBO Derivation

Decision Trees (ID3)

Information gain: I(F) = H(S) − Σᵥ (|Sᵥ|/|S|) H(Sᵥ) where H(S) = entropy of class distribution in S. Algorithm: 1. Compute class tallies for each feature value 2. Compute weighted post-split entropy for each feature 3. Pick feature with HIGHEST gain (= LOWEST weighted post-split entropy) 4. Recurse on each subset (remove used feature) 5. Stop when all instances in subset have same class Shortcut: if any split creates all-pure subsets → maximum gain, pick it.
Overfitting preventionHow
Max-depth stoppingHyperparameter, tune on validation set
Validation set pruningGrow full tree, then prune branches that don't improve validation
L1 regularization❌ Cannot — discrete model space

ELBO Derivation

Decomposition: ln p(x|θ) = L(q,θ) + KL(q,p) Proof (start from RHS): L + KL = E_q ln[p(x,z|θ)/q(z|x)] − E_q ln[p(z|x,θ)/q(z|x)] = E_q ln p(x,z|θ) − E_q ln q(z|x) − E_q ln p(z|x,θ) + E_q ln q(z|x) = E_q ln p(x,z|θ) − E_q ln p(z|x,θ) = E_q ln[p(x,z|θ)/p(z|x,θ)] = E_q ln[p(z|x,θ)p(x|θ)/p(z|x,θ)] = E_q ln p(x|θ) = ln p(x|θ) ✓ Since KL ≥ 0: ln p(x|θ) ≥ L(q,θ) → L is the variational LOWER BOUND. VAE decomposition of L: L(v,w) = E_q[ln p_w(x|z)] − KL(q_v(z|x), p_w(z)) = [reconstruction term] − [KL to prior]

Why can't we set KL=0? Would need p(z|x,θ) = invert the decoder. Intractable for neural networks. Instead: approximate with encoder q_v(z|x).

⚡ 10 Application Types — Step-by-Step Reference

These 10 types appear on every exam. Memorize the procedure, not just the formula.

Type 1: Find the gradient

Given: model y = f(x; w) (polynomial) Find: ∂loss/∂w Step 1: Write loss = ½(y − t)² Step 2: ∂loss/∂w = (y−t) · ∂y/∂w [chain rule] Step 3: Compute ∂y/∂w using differentiation rules Step 4: Optionally: w_new = w − η·∂loss/∂w Example: y = −vx² + wx + b ∂loss/∂w = (y−t)·x ∂loss/∂v = (y−t)·(−x²)

Type 2: Ranking and coverage matrix

Step 1: Apply classifier rule to each instance → get score Step 2: Sort: most negative score → left; most positive → right This is the ranking: [most-neg ... most-pos] Step 3: Build coverage matrix Rows = Pos instances (sorted top=most-pos) Cols = Neg instances (sorted left=most-neg) Step 4: Fill each cell (pos_row, neg_col): - GREEN if pos ranked higher than neg - RED if neg ranked higher than pos - YELLOW if tied Step 5: Count errors = #red + 0.5 × #yellow

Type 3: Entropy / cross-entropy / KL

H(p) = −Σₓ p(x) log₂ p(x) H(p,q) = −Σₓ p(x) log₂ q(x) → STOP if any q(x)=0 where p(x)>0: H(p,q) = undefined (∞) KL(p‖q) = H(p,q) − H(p) Tips: log₂(1/2) = −1, log₂(1/4) = −2, log₂(1/8) = −3 H(uniform over 4) = 2 bits exactly H(1/2, 1/4, 1/8, 1/8) = 1/2·1 + 1/4·2 + 1/8·3 + 1/8·3 = 1.75 bits

Type 4: Scalar backpropagation

Step 1: Name all intermediate variables (a, b, c, ...) Step 2: Draw computation graph Step 3: Compute local derivative at each node Step 4: Chain from loss back to target parameter Multivariate chain rule (diamond graph): ∂f/∂x = Σ_paths (product of local derivatives along each path) Example: f = sin(x²)cos(x³) Modules: a=sin(c), b=cos(d), c=x², d=x³, f=ab ∂f/∂x = b·cos(c)·2x + a·(−sin(d))·3x² = cos(x³)·cos(x²)·2x − sin(x²)·sin(x³)·3x²

Type 5: Decision trees

Step 1: Compute H(S) = −p(Yes)log₂p(Yes) − p(No)log₂p(No) Step 2: For each feature F: Tally: for each value v of F, count (Yes, No) class instances Compute: post-split entropy = Σᵥ (|Sᵥ|/|S|) H(Sᵥ) Step 3: Information gain I(F) = H(S) − post-split entropy(F) Pick feature with MAX I(F) Shortcut: if splitting makes all subsets pure → entropy = 0 → this feature wins. Entropy values to remember: H(1/2, 1/2) = 1.0 (max for binary) H(2/3, 1/3) ≈ 0.918 H(3/4, 1/4) ≈ 0.811 H(1, 0) = 0 (pure)

Type 6: ELBO derivation

To show: L(q,θ) + KL(q,p) = ln p(x|θ) Properties: p(a,b) = p(a|b)p(b) log(fg) = log f + log g log(f/g) = log f − log g E[f+g] = Ef + Eg E[constant] = constant Proof: L + KL = E_q ln[p(x,z|θ)/q(z|x)] − E_q ln[p(z|x,θ)/q(z|x)] = E_q [ln p(x,z|θ) − ln q(z|x) − ln p(z|x,θ) + ln q(z|x)] = E_q [ln p(x,z|θ) − ln p(z|x,θ)] = E_q ln [p(z|x,θ)p(x|θ) / p(z|x,θ)] = E_q ln p(x|θ) = ln p(x|θ) ✓

Type 7: Naive Bayes classification

WITHOUT smoothing: p̂(class|x) ∝ Πᵢ p(xᵢ|class) · p(class) Each factor = count(xᵢ=v, class) / count(class) Normalize: divide by sum over all classes WITH smoothing: Add one pseudo-observation per (feature value, class) New count = original_count + 1 New denominator = original_total + 2 (for binary feature) Warning: if any p(xᵢ|class) = 0 → product = 0 for that class → use smoothing to avoid this

Type 8: SVM support vectors

Given: w, b, and points {(xᵢ, yᵢ)} Step 1: Compute f(xᵢ) = wᵀxᵢ + b for each point Step 2: Class = sign(f(xᵢ)) [positive result → Pos, negative → Neg] Step 3: Support vector ↔ f(xᵢ) = yᵢ [exactly ±1] Decision boundary: wᵀx + b = 0 → x₂ = −(w₁/w₂)x₁ − b/w₂ Margin edges: wᵀx + b = ±1 → x₂ = −(w₁/w₂)x₁ + (1−b)/w₂ [positive edge] → x₂ = −(w₁/w₂)x₁ − (1+b)/w₂ [negative edge]

Type 9: Markov model classification

Given: bigram/unigram frequency table per class, email, prior Step 1: p(email|spam) = Π factors using chain rule + Markov assumption p(w₄|w₃,spam) = count("w₃ w₄" in spam) / count("w₃" in spam) p(w₁|spam) = count("w₁" in spam) / total words in spam Step 2: p(spam|email) ∝ p(email|spam) · p(spam) p(ham|email) ∝ p(email|ham) · p(ham) Step 3: Compare — pick larger Tip: work in fractions, cancel common factors before multiplying. Strong prior (e.g. p(spam)=1/40) can flip classification!

Type 10: Matrix backpropagation

Given: y = Wx + b, upstream gradient y∇ Return: b∇ = y∇ [same shape as b] x∇ = y∇ W [row vector × matrix W → same shape as x] W∇ = (y∇)ᵀ xᵀ [outer product → same shape as W] Key rule: NEVER compute full Jacobian. Always compute the Jacobian-vector product directly using multivariate chain rule: ∂L/∂bⱼ = Σᵢ yᵢ∇ · ∂yᵢ/∂bⱼ = yⱼ∇ For exam multiple choice: "compute upstream × local, not full Jacobian" = correct.
