Probability Rules
Addition Rule
P(A∪B) = P(A) + P(B) − P(A∩B)
For any two events. If disjoint (A∩B=∅): P(A∪B) = P(A)+P(B)
Complement
P(Aᶜ) = 1 − P(A)
Aᶜ = "A does not happen". Always use this to find "at least one" probabilities.
Triple Union — De Morgan
P(A∪B∪C) = 1 − P(Aᶜ∩Bᶜ∩Cᶜ)
If independent: = 1 − P(Aᶜ)·P(Bᶜ)·P(Cᶜ). Fastest method on exam.
Conditional Probability
P(A|B) = P(A∩B) / P(B)
A|B = "A given B". Restrict sample space to B, then ask about A.
Multiplication Rule
P(A∩B) = P(A|B) · P(B) = P(B|A) · P(A)
If independent: P(A∩B) = P(A)·P(B)
Independence Check
A,B independent ⟺ P(A∩B) = P(A)·P(B) ⟺ P(A|B) = P(A)
Independent ≠ Disjoint. Disjoint means P(A∩B)=0.
Bayes' Rule
P(A|B) = P(B|A) · P(A) / P(B)
P(A) = prior, P(B|A) = likelihood, P(B) = total prob of B. Use when you need to "flip" the conditioning.
Law of Total Probability
P(B) = P(B|A)·P(A) + P(B|Aᶜ)·P(Aᶜ)
Used to find P(B) when B can happen via two cases (e.g. two machines). Always the first step before Bayes.
Always True
P(A∩B) ≤ P(A∪B) P(C|C) = 1 P(A∪B∪C) = 1−P(Aᶜ∩Bᶜ∩Cᶜ)
P(A∪B|C) = P(A|C)+P(B|C) only if A∩B=∅. Not generally true.

Discrete Distributions
Distribution PMF P(X=k) E(X) Var(X) CDF / Notes
Bernoulli(p) p^k (1−p)^(1−k), k∈{0,1} p p(1−p) Single trial. Building block for Binomial.
Binomial(n, p) C(n,k) p^k (1−p)^(n−k) np np(1−p) Sum of n independent Bernoulli(p). Use CLT for large n.
Geometric(p) p(1−p)^(k−1), k=1,2,… 1/p (1−p)/p² Waiting for 1st success. F(k) = 1−(1−p)^k. F(2.5) = P(1)+P(2)
Pascal(m, p) C(k−1,m−1) p^m (1−p)^(k−m) m/p m(1−p)/p² Waiting for m-th success. Geometric is Pascal with m=1.
Poisson(λ) e^(−λ) λ^k / k!, k=0,1,… λ λ Events per interval. Scale: λ = rate × time. P(X>1.8) = P(X≥2)
CDF of discrete RV at non-integer x: F(x) = sum of all PMF values at integers ≤ x.
e.g. X ~ Geometric(0.2): F(2.5) = P(X=1) + P(X=2) = 0.2 + 0.2×0.8 = 0.36

Poisson scaling: if rate = 10/hr and window = 1.5 hrs → λ = 15.

Continuous Random Variables
PDF → Probability
P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx
f(x) = PDF. Probability = area under the curve. Always: f(x)≥0 and ∫f=1.
CDF from PDF
F(x) = P(X≤x) = ∫₋∞ˣ f(u) du
CDF is non-decreasing, right-continuous, F(−∞)=0, F(∞)=1. Not necessarily differentiable or strictly increasing.
PDF from CDF
f(x) = F'(x) = dF(x)/dx
Differentiate the CDF to get the PDF. Works wherever F is differentiable.
Finding Constant c
∫₋∞^∞ f(x) dx = 1 → solve for c
Set total integral = 1 and solve. Integrate only over the range where f(x) > 0.
Expected Value E(X)
E(X) = ∫₋∞^∞ x · f(x) dx
Integrate over the range only. Linearity: E(aX+b) = aE(X)+b
LOTUS — E[g(X)]
E[g(X)] = ∫₋∞^∞ g(x) · f(x) dx
E[X²] = ∫ x²·f(x) dx — NOT (∫xf dx)². Just swap x for g(x) inside the integral.
Variance
Var(X) = E(X²) − [E(X)]² = E[(X−μ)²]
μ = E(X). Shortcut: compute E(X²) via LOTUS, subtract [E(X)]². Var(aX+b) = a²Var(X)
Functions of RVs — CDF Method
F_Y(y) = P(g(X) ≤ y) → rearrange for X → express via F_X
Then differentiate to get f_Y(y). Works for Y = eˣ, Y = X², Y = √X, etc.
Sum of Independent RVs
E(X+Y) = E(X) + E(Y) Var(X+Y) = Var(X) + Var(Y) [if indep.]
Variances add for independent RVs — regardless of distribution. Means always add.

Special Continuous Distributions
Uniform(a, b)
f(x) = 1/(b−a) for a < x < b F(x) = (x−a)/(b−a) E(X) = (a+b)/2 Var(X) = (b−a)²/12
Flat PDF — all values equally likely. If X~U(0,1): F(x) = x.
Exponential(λ)
f(x) = λe^(−λx) for x > 0 F(x) = 1 − e^(−λx) E(X) = 1/λ Var(X) = 1/λ²
λ = rate (events per unit time). Memoryless: P(X>x+a|X>a) = P(X>x).
Normal N(μ, σ²)
f(x) = (1/σ√2π) e^(−(x−μ)²/2σ²) E(X) = μ, Var(X) = σ² Standardise: Z = (X−μ)/σ ~ N(0,1) P(X≤x) = Φ((x−μ)/σ)
μ = mean, σ² = variance, σ = std dev. Always standardise first, then use Φ table.
Φ Symmetry Rules
Φ(−x) = 1 − Φ(x) Φ(0) = 0.5 P(X > a) = 1 − Φ((a−μ)/σ)
Use symmetry when you get a negative z-score. Φ(−1) = 1−Φ(1) — they're equal.
Linear Transform of Normal
X ~ N(μ,σ²), Y = aX+b → Y ~ N(aμ+b, a²σ²)
Linear transforms of normals stay normal. σ_Y = |a|·σ_X. Sum of independent normals is also normal.
Sum of Independent Normals
X~N(μ_X,σ²_X), Y~N(μ_Y,σ²_Y) indep. Z = X+Y → N(μ_X+μ_Y, σ²_X+σ²_Y)
Variances add (not standard deviations!). Subtract: Z=X−Y has variance σ²_X + σ²_Y.

Law of Large Numbers & Central Limit Theorem
Sample Mean
X̄ₙ = (X₁+…+Xₙ)/n E(X̄ₙ) = μ Var(X̄ₙ) = σ²/n
μ, σ² = mean/variance of each Xᵢ. Var shrinks with n — taking more data reduces uncertainty.
Weak Law of Large Numbers
X̄ₙ → μ as n → ∞ lim P(|X̄ₙ−μ| ≥ ε) = 0
The sample average converges to the true mean. More data = closer estimate. Applies to any distribution with finite mean.
Central Limit Theorem (CLT)
X̄ₙ ~ N(μ, σ²/n) approximately Sum Y=ΣXᵢ ~ N(nμ, nσ²) Z = (X̄ₙ−μ)/(σ/√n) ~ N(0,1)
Requires: X₁,…,Xₙ iid with mean μ, variance σ². Works for any distribution if n is large.
Applying CLT — Step by Step
1. Identify μ=E(Xᵢ), σ²=Var(Xᵢ) 2. Write Y = X₁+…+Xₙ → Y ~ N(nμ, nσ²) 3. Standardise: Z = (Y−nμ)/(σ√n) ~ N(0,1) 4. P(Y≤c) = Φ((c−nμ)/(σ√n))
Binomial shortcut: X~Bin(n,p) → μ=np, σ²=np(1−p), then use CLT.    For quantile problems: set Φ(z)=0.95 → z=1.645, then solve for the unknown.
θ̂
Point Estimation & MLE
Bias
Bias(Θ̂) = E(Θ̂) − θ
If Bias=0: unbiased. X̄ is always unbiased for μ. S² (with n−1) is unbiased for σ².
MSE — Bias-Variance Tradeoff
MSE(Θ̂) = E[(Θ̂−θ)²] = Var(Θ̂) + [Bias(Θ̂)]²
If unbiased: MSE = Var(Θ̂). For X̄: MSE = Var(X̄) = σ²/n.
Consistency
Θ̂ₙ consistent ⟺ lim P(|Θ̂ₙ−θ| < ε) = 1 Sufficient: MSE(Θ̂ₙ) → 0
X̄ₙ is consistent for μ because Var(X̄ₙ)=σ²/n→0.
Sample Variance S²
S² = 1/(n−1) · Σᵢ(Xᵢ−X̄)² E(S²) = σ² ← unbiased
Use n−1 (Bessel's correction). The biased version uses n: E(S̄²) = (n−1)/n · σ².
Likelihood Function
Discrete: L(θ) = Π P(Xᵢ=xᵢ; θ) Continuous: L(θ) = Π f(xᵢ; θ)
Product of PDFs/PMFs evaluated at your data. Measures how likely the data is under parameter θ.
MLE — Maximum Likelihood
1. Write L(θ) = Π f(xᵢ; θ) 2. Take log: ℓ(θ) = Σ log f(xᵢ; θ) 3. Solve: dℓ/dθ = 0
Log doesn't change the argmax. MLE for Exp(λ): λ̂ = 1/x̄. MLE for Binomial(m,θ): θ̂ = x̄/m.

Confidence Intervals
What to estimate Conditions Formula Pivot distribution
Mean μ σ² known, any n X̄ ± z_{α/2} · σ/√n Z = (X̄−μ)/(σ/√n) ~ N(0,1)
Mean μ σ² unknown, large n X̄ ± z_{α/2} · S/√n Z ≈ N(0,1) by CLT
Mean μ Normal pop., σ² unknown, small n X̄ ± t_{α/2, n−1} · S/√n T = (X̄−μ)/(S/√n) ~ t_{n−1}
Proportion p Large n (Bernoulli data) p̂ ± z_{α/2} · √(p̂(1−p̂)/n) Z ≈ N(0,1) by CLT, p̂ = X̄
Variance σ² Normal population, μ unknown [ (n−1)S²/χ²_{α/2,n−1} , (n−1)S²/χ²_{1−α/2,n−1} ] (n−1)S²/σ² ~ χ²_{n−1}
WRONG interpretation: "There's a 95% chance μ lies in [a,b]." — θ is fixed, not random.
CORRECT: "If we repeated this experiment many times, 95% of computed intervals would contain μ." The interval is random, θ is not.
CI width: Larger n → narrower CI (σ/√n shrinks). Higher confidence level → wider CI (larger z). So: 99% CI is wider than 95% CI.  |  Sample size for margin m: n ≥ (z_{α/2} · σ / m)²
H
Hypothesis Testing
Error Types
Type I: reject H₀ when H₀ TRUE P(Type I) = α ← you control this Type II: accept H₀ when H₁ TRUE P(Type II) = β
Larger rejection region → smaller β but larger α. Bigger R → fewer missed detections.
Test Statistic for Mean
W = (X̄ − μ₀) / (σ/√n) [z-test] T = (X̄ − μ₀) / (S/√n) [t-test]
μ₀ = null value. Use z-test if σ known or n large. Use t-test (t_{n−1}) if σ unknown + small n + normal pop.
Rejection Regions
Two-sided (H₁: μ≠μ₀): |W| > z_{α/2} Right-sided (H₁: μ>μ₀): W > z_{α} Left-sided (H₁: μ<μ₀): W < −z_{α}
Reject H₀ if W falls in rejection region. P(Type I error) = α — set this before the test.
P-value
Two-sided: p = 2·(1−Φ(|w|)) Right-sided: p = 1−Φ(w) = P(Z>w) Left-sided: p = Φ(w) = P(Z
w = observed test statistic. Reject H₀ if p < α. Smaller p = stronger evidence against H₀.
Computing Type I Error Probability
P(Type I) = P(reject H₀ | H₀ true) = P(X̄ > c | μ=μ₀) = P(Z > (c−μ₀)/(σ/√n))
Standardise X̄ under H₀, then use Φ. Example: reject if X̄>1.5, n=9, σ=1, μ₀=1: P(Type I) = 1−Φ(3/2).
Likelihood Ratio Test (LRT)
λ(x) = L(x; θ₀) / L(x; θ₁) Accept H₀ if λ ≥ c Reject H₀ if λ < c
For simple H₀:θ=θ₀ vs H₁:θ=θ₁. Choose c so P(Type I) ≤ α. Reduces to comparing which θ makes data more likely.
α and p-value relationship: If rejected at α=0.025, it IS also rejected at α=0.05 (since 0.025 < 0.05). But it may NOT be rejected at α=0.01. Rule: rejected at α ⟺ p-value < α.
