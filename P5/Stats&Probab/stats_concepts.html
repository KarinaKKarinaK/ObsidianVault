Probability · appears every exam
Bayes' rule
Highest frequency — appears in every single paper
Intuition
You observe something surprising. Bayes tells you how to update your belief about a cause given that effect.

Classic form: "Given that the item is defective, what's the probability it came from Machine A?" — you already know how likely A produces defects, now you flip it.
When to use
Any question of the form "Given [observation], what's the probability of [cause]?"

Triggers: "given it's defective…", "given a positive test…", "given she tests negative…".

You need: P(cause), P(observation | cause), P(observation).
Formula
P(A | B) = P(B | A) · P(A) / P(B)

where P(B) = P(B|A)·P(A) + P(B|Aᶜ)·P(Aᶜ) [law of total probability]
Strategy — step by step
1
Label your events. Define cause = A, observation/effect = D (or B). Write down what you know: P(A), P(D|A), and either P(D) directly or P(D|Aᶜ) so you can compute P(D).
2
If P(D) isn't given, compute it using total probability: P(D) = P(D|A)·P(A) + P(D|Aᶜ)·P(Aᶜ). This is often a sub-question.
3
Apply Bayes: P(A|D) = P(D|A)·P(A) / P(D). Divide numerator by the full denominator. Plug, compute, round.
Common mistake
Confusing P(A|D) with P(D|A). They are not the same. "What's the probability of rain given clouds?" ≠ "What's the probability of clouds given rain?" Always ask: which is the cause, which is the observation?
Worked pattern (exam-style)
Machine defect example
P(A)=0.6, P(D|A)=0.02, P(D)=0.1
P(A|D) = 0.02 × 0.6 / 0.1 = 0.12

Probability rules
Addition rule
P(A∪B) = P(A) + P(B) − P(A∩B)

The overlap gets counted twice so subtract it once.
Complement rule
P(Aᶜ) = 1 − P(A)

Also: P(A∪B∪C) = 1 − P(Aᶜ∩Bᶜ∩Cᶜ)
Much easier than expanding.
Independence
A,B independent ⟺ P(A∩B) = P(A)·P(B)

Independent ≠ disjoint. Disjoint means P(A∩B)=0.
P(A∪B∪C) — the complement trick (exam favourite)
P(A∪B∪C) = 1 − P(Aᶜ)·P(Bᶜ)·P(Cᶜ) [if A,B,C independent]

e.g. P(A)=0.4, P(B)=0.5, P(C)=0.3 → 1 − 0.6 × 0.5 × 0.7 = 0.79
True/false traps on every paper

Probability · appears every exam
Conditional probability
Intuition
You restrict the sample space to only the outcomes where B occurred, then ask how many of those have A. You're zooming in on a subset.
Definition
P(A | B) = P(A ∩ B) / P(B)

Read: "probability of A, given B already happened".
Denominator: size of the new (restricted) universe.
Dice / coin exam questions — the enumeration approach
1
List all outcomes satisfying the "given" condition. This is your new sample space. Don't use all 36 dice outcomes — use only the ones matching the condition.
2
Count how many of those also satisfy the event you want.
3
Divide (count of wanted) / (count of condition).
Dice example — P(sum=7 | exactly one die shows 3)
Outcomes with exactly one 3: (3,1),(3,2),(3,4),(3,5),(3,6),(1,3),(2,3),(4,3),(5,3),(6,3) = 10
Of those, sum=7: (3,4) and (4,3) = 2
P = 2/10 = 1/5
Coin problem pattern
When asked "given at least one heads, P(at least two heads)?": note that {≥2 heads} ⊆ {≥1 heads}, so the intersection equals the smaller event.
P(A₂|A₁) = P(A₂∩A₁)/P(A₁) = P(A₂)/P(A₁) = (4/8)/(7/8) = 4/7

Some questions write N(3,4) meaning μ=3, σ²=4 → σ=2. Others write N(3,1) meaning σ=1 (same thing since σ²=1). The standardisation step Z=(X−μ)/σ always uses σ (the standard deviation), not σ². Always take the square root before standardising.
Distributions · appears every exam
Normal distribution & standardising
The core move
Any N(μ,σ²) question becomes a standard N(0,1) question by subtracting μ and dividing by σ. The CDF Φ only works for standard normal.
The symmetry trick
Φ(−z) = 1 − Φ(z)

P(Z > z) = 1 − Φ(z)
P(Z > −z) = Φ(z)

You only ever need the upper half of the table.
Standardisation
X ~ N(μ, σ²)
P(X > c) = P(Z > (c − μ) / σ) = 1 − Φ((c − μ) / σ)

e.g. X~N(3,4): P(X>4) = P(Z>(4−3)/2) = P(Z>0.5) = 1−Φ(0.5)
Linear transforms
Y = aX + b, where X ~ N(μ, σ²)
E[Y] = a·μ + b
Var[Y] = a²·σ²
σ_Y = |a|·σ

e.g. Y=2X−1, X~N(2,1): E[Y]=3, Var[Y]=4, so Y~N(3,4)
Sum of independent normals
X~N(μ₁,σ₁²), Y~N(μ₂,σ₂²) independent
X+Y ~ N(μ₁+μ₂, σ₁²+σ₂²)

Variances add — not standard deviations!
σ² adds, σ doesn't
If X~N(3,1) and Y~N(−3,2) where 2 is σ (not σ²), then Var[X+Y] = 1² + 2² = 5, so Z=X+Y~N(0,5). Read carefully whether the parameter is σ or σ².
Distributions · appears every exam
Expectation & LOTUS
Intuition — E[X]
The long-run average. Weight each possible value by its probability and sum up. It's the centre of mass of the distribution.
LOTUS intuition
To find E[g(X)], you don't need the distribution of g(X). Just plug g(x) into the expectation integral/sum directly, using the original distribution of X.
LOTUS — Law of the Unconscious Statistician
E[g(X)] = ∫ g(x) · f_X(x) dx [continuous]
E[g(X)] = Σ g(x) · P(X=x) [discrete]

Most common: g(X) = X², so E[X²] = ∫ x² · f_X(x) dx
Variance from LOTUS
Var(X) = E[X²] − (E[X])²
So: E[X²] = Var(X) + (E[X])²

e.g. X~Bin(10,0.2): E[X]=2, Var(X)=1.6, so E[X²]=1.6+4=5.6
Computing E[X] for continuous distributions
1
Write E[X] = ∫ x · f(x) dx over the support of X.
2
Multiply: x · f(x), then integrate. Use power rule: ∫ xⁿ dx = xⁿ⁺¹/(n+1).
3
Evaluate bounds. If support is [1,∞), upper bound gives 0 for negative powers (e.g. [x⁻¹]₁^∞ = 0 − (−1) = 1).
Worked — f(x)=3x⁻⁴ for x>1
E[X] = ∫₁^∞ x · 3x⁻⁴ dx = 3∫₁^∞ x⁻³ dx
= 3 · [x⁻²/(−2)]₁^∞ = 3 · (0 − (−1/2)) = 3/2 = 1.5
Distributions · appears every exam
PDF, PMF, and CDF
PDF (continuous)
f(x) — height of the density curve. Area under it = probability.

Must satisfy: f(x)≥0 and ∫f(x)dx = 1.
PMF (discrete)
P(X=k) — direct probability of each value.

Must satisfy: Σ P(X=k) = 1.
CDF (both)
F(x) = P(X≤x)

For continuous: F(x) = ∫₋∞ˣ f(t)dt
For discrete: F(x) = Σ_{k≤x} P(X=k)
CDF properties — always true
1. Non-decreasing (never goes down)
2. Right-continuous (not left-continuous)
3. lim_{x→−∞} F(x) = 0, lim_{x→+∞} F(x) = 1
4. For continuous: F'(x) = f(x) (PDF is derivative of CDF)
Geometric CDF — classic exam trap
F_X(2.5) for Geometric(p)
CDF at non-integer: F(2.5) = P(X≤2) = P(X=1) + P(X=2)
= p + (1−p)·p

e.g. p=0.2: F(2.5) = 0.2 + 0.8·0.2 = 0.36
Finding c to normalise a PDF
1
Set ∫ c·g(x) dx = 1 over the support.
2
Compute ∫ g(x) dx (the integral without c).
3
c = 1 / (that integral).
f(x) = ce⁻ˣ for 1 < x < 2
∫₁² e⁻ˣ dx = [−e⁻ˣ]₁² = e⁻¹ − e⁻² = (e−1)/e²
c = e²/(e−1) ≈ 3.16
Inference · appears every exam
Confidence intervals
Intuition
If you repeated this experiment 100 times and built a CI each time, about 95 of those intervals would contain the true parameter. It's a statement about the procedure, not the specific interval.
Width vs. confidence
Larger n → narrower CI (more data → more precision).
Higher confidence (99% vs 95%) → wider CI (you need a bigger net to be more sure).
These two facts appear as true/false on every paper.
CI for mean — σ known
X̄ ± z_{α/2} · σ/√n

90% → z=1.645, 95% → z=1.96, 99% → z=2.58
CI for proportion
p̂ ± z_{α/2} · √(p̂(1−p̂)/n)

where p̂ = x/n (sample proportion)

e.g. 240/400, 99%: 0.6 ± 2.58·√(0.24/400) = 0.6 ± 0.063 = (0.54, 0.66)
CI for σ² (chi-square)
[(n−1)s²/χ²_{α/2,n−1}, (n−1)s²/χ²_{1−α/2,n−1}]

e.g. n=16, s²=0.04: (n−1)s²=0.6
95% CI = [0.6/27.49, 0.6/6.26] = [0.022, 0.096]
Sample size calculation
Minimum n for margin of error m
n ≥ (z_{α/2} / m)² · p̂(1−p̂)

Conservative: use p̂(1−p̂) ≤ 0.25 (maximised at p̂=0.5)

90%, m=3%: n ≥ (1.645/0.03)² · 0.25 ≈ 752 → round up to n=800
Inference · appears every exam
Hypothesis testing
Intuition
Assume H₀ is true. Compute how surprising your data would be under that assumption. If the data is too surprising (p-value small), you reject H₀.
p-value
The probability of seeing data as or more extreme than what you observed, assuming H₀ is true.

p ≤ α → reject H₀.
p > α → fail to reject H₀. (Never "accept".)
Test statistic (z-test, σ known)
W = (X̄ − μ₀) / (σ/√n)

Left-tail (H₁: μ<μ₀): p = Φ(W)
Right-tail (H₁: μ>μ₀): p = 1−Φ(W)
Two-tail (H₁: μ≠μ₀): p = 2·min(Φ(W), 1−Φ(W))
Test statistic (t-test, σ unknown)
T = (X̄ − μ₀) / (S/√n) ~ t(n−1)

S is the sample standard deviation.
e.g. n=9, X̄=165.8, μ₀=170, S=8.25: T=(165.8−170)/(8.25/3)=−1.53
Computing a p-value from scratch
1
Compute the test statistic W = (X̄ − μ₀)/(σ/√n). Note the sign — it matters for the tail.
2
Identify the tail from H₁. H₁:μ<μ₀ → left tail. H₁:μ>μ₀ → right tail.
3
Convert to Φ. Left tail: p = Φ(W). Right tail: p = 1−Φ(W). If W is negative: Φ(negative) is a small number.
Exam pattern
H₀:μ=25, H₁:μ<25. X̄=24, n=36, σ=6.
W = √36·(24−25)/6 = 6·(−1)/6 = −1
Left-tail: p = Φ(−1)
Inference · appears every exam
Type I & Type II errors
Type I error (α)
False positive. You reject H₀ when H₀ is actually true. You fired an innocent person. Also called the significance level α.
Type II error (β)
False negative. You fail to reject H₀ when H₀ is actually false. You let a guilty person go free. Power = 1−β.
Memory device
Reality \ DecisionDon't reject H₀Reject H₀
H₀ is TRUECorrect ✓Type I error (α)
H₀ is FALSEType II error (β)Correct ✓ (Power)
Computing Type I error probability directly
1
Assume H₀ is true. Use the value μ₀ given in H₀.
2
Find P(reject H₀ | μ=μ₀). This is P(X̄ falls in rejection region | μ=μ₀).
3
Standardise X̄: Z = (X̄ − μ₀)/(σ/√n) and express as Φ.
Exam pattern — P(Type I)
X₁,...,X₉~N(μ,1). Reject if X̄>1.5. H₀:μ=1.
P_{μ=1}(X̄>1.5) = P(Z > (1.5−1)/(1/√9)) = P(Z>1.5) = 1−Φ(3/2)
True/false patterns on this topic
"Rejected at α=0.025 → must reject at α=0.05" — TRUE (p≤0.025 < 0.05).
"Rejected at α=0.025 → must reject at α=0.01" — FALSE (p could be between 0.01 and 0.025).
"Larger rejection region → smaller Type II error" — TRUE (easier to reject → less missed positives).
"P(Type II) = P(not rejecting H₀ when H₀ true)" — FALSE (that's just a correct decision).
Inference · appears every exam
Maximum likelihood estimation
Intuition
Find the parameter value that makes the observed data most probable. Ask: "For which θ is it most likely I would have seen these exact observations?"
Strategy
1. Write L(θ) = ∏ f(xᵢ; θ)
2. Take log: ℓ(θ) = Σ log f(xᵢ; θ)
3. Differentiate wrt θ, set = 0
4. Solve for θ̂
Key MLE results to memorise
Exponential(λ): λ̂ = 1/x̄ (not x̄ itself)
Normal(μ,σ²): μ̂ = x̄, σ̂² = Σ(xᵢ−x̄)²/n
Binomial(n,θ): θ̂ = x̄/n = sample proportion
Geometric(θ): θ̂ = 1/x̄ (= n/Σxᵢ)
Poisson(λ): λ̂ = x̄
Computing from a given likelihood function
1
Take ℓ(θ) = log L(θ). For L=θᵃ(1−θ)ᵇ: ℓ = a·log(θ) + b·log(1−θ).
2
Differentiate: dℓ/dθ = a/θ − b/(1−θ).
3
Set = 0 and solve: a(1−θ) = bθ → θ̂ = a/(a+b).
L(θ) = 12θ³(1−θ)⁵ → MLE
a=3, b=5 → θ̂ = 3/(3+5) = 3/8 = 0.375 ≈ 0.38
Exponential MLE trap
For Exponential(λ), the MLE is λ̂ = 1/x̄. The exam asks "does MLE equal the sample mean?" — the answer is no for Exponential. The sample mean estimates 1/λ, not λ itself.
Limit theorems · appears every exam
CLT & sample mean
Intuition
No matter what distribution your Xᵢ come from, if you average enough of them, the average becomes approximately normal. The bell curve emerges from chaos.
Why it matters
It's why we can use z-scores for CIs and hypothesis tests on any population — we just need n large enough (usually n≥30) for the CLT to kick in.
CLT statement
X₁,...,Xₙ iid with mean μ and variance σ²

X̄ ≈ N(μ, σ²/n) for large n

Equivalently: √n·(X̄−μ)/σ → N(0,1)

Var(X̄) = σ²/n (always exact, regardless of n)
CLT for sums
Sₙ = X₁+…+Xₙ ≈ N(nμ, nσ²)

Standardise: Z = (Sₙ − nμ) / (σ√n)

e.g. n=1000, μ=0.4, σ²=1:
P(S≤400) = P(Z≤(400−400)/√1000) = Φ(0) = 0.5
CLT for Binomial approximation
X~Bin(n,p), approximate P(X>k) via CLT
μ=np, σ²=np(1−p)
Z = (k − μ)/σ, then P(X>k) ≈ 1−Φ(Z)

e.g. X~Bin(20,1/5): μ=4, σ²=16/5
P(X>8) ≈ 1−Φ((8−4)/√(16/5)) = 1−Φ(√5)
Unbiasedness — always true
E[X̄] = μ always (for any n, any distribution). The sample mean is always an unbiased estimator of the population mean. This appears as a true/false in every exam.

Symmetry rules — use these constantly
Φ symmetry identities
Φ(−z) = 1 − Φ(z)
P(Z>z) = 1 − Φ(z)
P(Z>−z) = Φ(z)
P(−z ≤ Z ≤ z) = 2Φ(z) − 1

e.g. Φ(−1) = 1−Φ(1) ≈ 0.159
