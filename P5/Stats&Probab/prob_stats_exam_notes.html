Ch. 4Continuous Random Variables
Introduction

Unlike discrete RVs (countable values), continuous random variables take values over intervals on ℝ. Because they can take uncountably many values, P(X = x) = 0 for every single point — so there's no PMF. Instead we use the PDF.

Definition — Continuous RV
A random variable X with CDF FX is continuous if FX(x) is continuous for all x ∈ ℝ (no jumps). The key consequence: P(X = x) = 0 for all x.
Definition — Range RX
The range of a continuous RV is RX = {x : fX(x) > 0} — the set of all values where the PDF is positive.
PDF & CDF
Definition — PDF
The probability density function is the derivative of the CDF:
Formula
fX(x) = dFX(x)/dx = F'X(x)

Three essential properties that every valid PDF must satisfy:

  • fX(x) ≥ 0 for all x ∈ ℝ
  • ∫−∞∞ fX(u) du = 1 (integrates to 1)
  • P(a < X ≤ b) = ∫ab fX(u) du = FX(b) − FX(a)
⚡ Key Insight
CDF → PDF: Differentiate.   PDF → CDF: Integrate from −∞.
FX(x) = ∫−∞x fX(u) du
📋 Worked Example — Finding c and the CDF
Let fX(x) = ce−x for x ≥ 0, zero otherwise. Find c and FX(x).
Solution
Since ∫0∞ ce−xdx = c[−e−x]0∞ = c = 1, so c = 1.

For x ≥ 0: FX(x) = ∫0x e−udu = 1 − e−x. For x < 0: FX(x) = 0.
Expected Value & Variance
Discrete
E(X) = Σ x · PX(x)

E[g(X)] = Σ g(x) PX(x)
Continuous
E(X) = ∫−∞∞ x fX(x) dx

E[g(X)] = ∫−∞∞ g(x) fX(x) dx
LOTUS — Law of the Unconscious Statistician
To compute E[g(X)], you do NOT need to find the distribution of g(X) — just integrate g(x) against fX(x):
Formula
E[g(X)] = ∫−∞∞ g(x) fX(x) dx
Variance formulas
Formula
Var(X) = E[(X − μ)²] = E(X²) − [E(X)]² Var(aX + b) = a² Var(X) E(aX + b) = a E(X) + b
📋 Worked Example — E(X) for Uniform(a, b)
fX(x) = 1/(b−a) for a < x < b.
Solution
E(X) = ∫ab x/(b−a) dx = (1/(b−a)) · [x²/2]ab = (a+b)/2
Functions of Continuous RVs

If X is a continuous RV and Y = g(X), to find the distribution of Y:

  1. Find the range RY
  2. Find the CDF: FY(y) = P(Y ≤ y) = P(g(X) ≤ y) — rewrite in terms of X
  3. Differentiate to get fY(y) = F'Y(y)
📋 Worked Example — Y = eX, X ~ Uniform(0,1)
Find the CDF and PDF of Y.
Solution
Range: RY = [1, e]. For 1 ≤ y < e:
FY(y) = P(eX ≤ y) = P(X ≤ ln y) = ln y
Differentiate: fY(y) = 1/y for 1 ≤ y < e.

Using LOTUS: E(Y) = E(eX) = ∫01 ex dx = e − 1
📋 Worked Example — Y = X², X ~ Uniform(−1, 1)
Solution
Range: RY = [0, 1]. For 0 ≤ y ≤ 1:
FY(y) = P(X² ≤ y) = P(−√y ≤ X ≤ √y) = √y
Differentiate: fY(y) = 1/(2√y) for 0 ≤ y ≤ 1.

X ~ Uniform(a, b)

PropertyFormula

Exponential Distribution

Models the time between events (e.g. customer arrivals, radioactive decay). Continuous analogue of the Geometric distribution.

X ~ Exponential(λ), λ > 0 (rate parameter)

PropertyFormula
PDFfX(x) = λe−λx for x > 0, else 0
CDFFX(x) = 1 − e−λx for x ≥ 0
E(X)1/λ
Var(X)1/λ²
Memoryless Property
Formula
P(X > x + a | X > a) = P(X > x) for a, x ≥ 0

If you've been waiting a seconds with no arrival, the distribution of remaining wait time is the same as the original — as if you started fresh.

⚡ Proof technique
P(X > x+a | X > a) = P(X > x+a) / P(X > a) = e−λ(x+a) / e−λa = e−λx = P(X > x)
Normal (Gaussian) Distribution
Standard Normal Z ~ N(0, 1)
PDF
fZ(z) = (1/√(2π)) · e^(−z²/2)
CDF: Φ(x) = P(Z ≤ x) — no closed form, use tables/software.
Key: E(Z) = 0, Var(Z) = 1
General Normal X ~ N(μ, σ²)
Definition via Z
X = σZ + μ where Z ~ N(0,1)
E(X) = μ,  Var(X) = σ²

Calculating Normal Probabilities — Standardise!

CDF formula
P(X ≤ x) = Φ((x − μ)/σ) P(a < X ≤ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)

Symmetry rules you must know:

Symmetry
Φ(−x) = 1 − Φ(x) Φ(0) = 1/2
📋 Worked Example — X ~ N(−5, 4)
Find P(X < 0) and P(X > −3 | X > −5). Note: σ = √4 = 2.
Solution
P(X < 0) = P(Z < (0−(−5))/2) = P(Z < 2.5) = Φ(2.5) ≈ 0.994

P(X > −3 | X > −5) = P(X > −3)/P(X > −5)
= P(Z > 1) / P(Z > 0) = (1−Φ(1))/(1−Φ(0)) ≈ 0.1587/0.5 ≈ 0.317
⚡ Linear Transformations of Normals
If X ~ N(μX, σX²) and Y = aX + b, then Y ~ N(aμX + b, a²σX²). Linear transforms of normals stay normal!
Ch. 7Limit Theorems & Convergence
The Sample Mean

Let X1, …, Xn be iid with mean μ and variance σ². The sample mean is:

Definition
X̄n = (1/n) Σ Xi

Key properties of the sample mean:

Properties
E(X̄n) = μ ← unbiased Var(X̄n) = σ²/n ← variance shrinks with n
Weak Law of Large Numbers (WLLN)
Theorem — WLLN
Let X1, …, Xn be iid with finite mean μ. For any ε > 0:
Statement
limn→∞ P(|X̄n − μ| ≥ ε) = 0
Equivalently: limn→∞ P(μ − ε < X̄n < μ + ε) = 1

In plain English: As you take more samples, the sample average converges in probability to the true mean. Relative frequencies converge to probabilities. Histograms converge to the true distribution.

Proof sketch
Apply Chebyshev's inequality to X̄n: P(|X̄n − μ| ≥ ε) ≤ Var(X̄n)/ε² = σ²/(nε²) → 0
Central Limit Theorem (CLT)
Theorem — CLT
Let X1, …, Xn be iid with mean μ and variance σ². Define:
Standardised average
Zn = (X̄n − μ) / (σ/√n)
Then limn→∞ P(Zn ≤ x) = Φ(x).

In other words: X̄n ~ N(μ, σ²/n) approximately for large n.

In terms of the sum Y = X1 + ⋯ + Xn:

Sum version
E(Y) = nμ, Var(Y) = nσ² (Y − nμ) / (σ√n) ~ N(0, 1) approximately
Applying the CLT — Step-by-Step
  1. Write Y = X1 + ⋯ + Xn where the Xi are iid. Identify μ = E(Xi) and σ² = Var(Xi).
  2. Standardise: Z = (Y − nμ) / (σ√n) ~ N(0,1)
  3. Convert the probability: P(y1 ≤ Y ≤ y2) ≈ Φ((y2−nμ)/(σ√n)) − Φ((y1−nμ)/(σ√n))
📋 Worked Example — Bit errors
1000 bits, each has error probability 0.1 independently. Find P(Y > 120).
Solution
Each bit: Xi ~ Bernoulli(0.1), so μ = 0.1, σ² = 0.09.
P(Y > 120) = P(Z > (120 − 100)/√90) = P(Z > 20/√90) ≈ 1 − Φ(2.11) ≈ 0.0175
📋 Worked Example — Sandwiches (finding quantile)
64 guests, each needs 0/1/2 sandwiches with prob 1/4, 1/2, 1/4. Find y so P(Y ≤ y) = 0.95.
Solution
μ = 1, σ² = 1/2, n = 64.
P(Y ≤ y) ≈ Φ((y − 64)/(4√2)) = 0.95
So (y − 64)/(4√2) = Φ−1(0.95) ≈ 1.645
y = 64 + 1.645 × 4√2 ≈ 73.3 → make 74 sandwiches
Continuity Correction

When Y is a discrete RV (sum of integer-valued iid RVs), the CLT normal approximation improves with continuity correction:

Continuity Correction Rule
Formula
P(l ≤ Y ≤ u) ≈ P(l − 1/2 ≤ Y ≤ u + 1/2) [use normal approx on right]
When to use it
Use continuity correction when the Xi are integer-valued (Bernoulli, Poisson, etc.) and n is not huge. It shifts the boundary by 0.5 to account for the discrete→continuous mismatch.
Ch. 8Statistical Inference I: Classical Methods
Setup & Random Samples
Definition — Random Sample
X1, …, Xn is a random sample of size n if the Xi are independent and identically distributed (iid). We always assume finite E(Xi) and Var(Xi).

The core idea: Observations = realisations of RVs. Reformulate research questions as questions about unknown parameters θ of the distribution.

Point Estimation
Definition — Point Estimator
A point estimator Θ̂ = h(X1, …, Xn) is any function of the sample used to estimate parameter θ. It is a random variable.

Example: estimating θ = E(X) — natural estimator is the sample mean Θ̂ = X̄n.

Bias, MSE & Consistency
Bias
Definition
B(Θ̂) = E(Θ̂) − θ
If B(Θ̂) = 0 for all θ: unbiased. Otherwise: biased.
Mean Squared Error (MSE) — Bias-Variance Tradeoff
Decomposition
MSE(Θ̂) = E[(Θ̂ − θ)²] = Var(Θ̂) + [B(Θ̂)]²

Better estimator = lower MSE. Two unbiased estimators? Compare by variance.

Consistent Estimator
Definition
limn→∞ P(|Θ̂n − θ| < ε) = 1 for all ε > 0
Sufficient condition: If limn→∞ MSE(Θ̂n) = 0, then Θ̂n is consistent.
📋 Worked Example — Bias of max estimator
X ~ Uniform(0, θ). Estimator Θ̂2 = max{X1, …, Xn}. Find bias.
Solution
CDF of max: FΘ̂₂(y) = (y/θ)^n. PDF: f(y) = ny^(n-1)/θ^n.
E(Θ̂2) = ∫0θ y · nyn-1/θn dy = n/(n+1) · θ
Bias = −θ/(n+1). Biased (underestimates). Bias → 0 as n → ∞.
📋 Worked Example — X̄n beats X1
Both X1 and X̄n are unbiased for μ. Compare MSE for n > 1.
Solution
Unbiased → MSE = Variance. Var(X1) = σ² vs Var(X̄n) = σ²/n.
Since n > 1: X̄n is better (lower MSE).
Sample Variance
Definition — Sample Variance S²
Definition
S² = (1/(n−1)) Σi=1n (Xi − X̄)²
S² is an unbiased estimator for σ²: E(S²) = σ².
⚠ Common Mistake
The "naive" estimator S̄² = (1/n) Σ(Xi − X̄)² is biased: E(S̄²) = (n−1)/n · σ². Always use n−1 (Bessel's correction) for unbiasedness. Sample SD S = √S² is biased for σ (but still the standard estimator).
Maximum Likelihood Estimation (MLE)
Likelihood Function
For discrete Xi
L(x1,…,xn; θ) = P(X1=x1) · … · P(Xn=xn)
For continuous Xi
L(x1,…,xn; θ) = fX(x1) · … · fX(xn)
MLE — Maximum Likelihood Estimate
θ̂ML = value of θ that maximises L(x1,…,xn; θ).

In practice: maximise log L instead (log is monotone, so same argmax). Set d(log L)/dθ = 0 and solve.
  1. Write the likelihood L(θ) as a product of the PDFs/PMFs
  2. Take log L(θ) — turns products into sums
  3. Differentiate w.r.t. θ and set equal to 0
  4. Verify it's a maximum (check second derivative or endpoint behaviour)
📋 MLE for Exponential(λ)
Sample x1, …, xn from Exp(λ).
Solution
L(λ) = λn e−λΣxi
log L = n log λ − λ Σxi
d(log L)/dλ = n/λ − Σxi = 0
λ̂ML = n/Σxi = 1/x̄
📋 MLE for Binomial(m, θ)
Sample x1, …, xn from Binomial(m, θ).
Solution
L(θ) ∝ θs(1−θ)mn−s where s = Σxi
log L = s log θ + (mn−s) log(1−θ)
Setting derivative to 0: θ̂ML = s/(mn) = x̄/m
MLE asymptotic properties
For large n, Θ̂ML is: (1) consistent, (2) asymptotically unbiased, (3) approximately N(θ, Var(Θ̂ML)).
Confidence Intervals
Definition — (1−α)100% Confidence Interval
Estimators Θ̂l and Θ̂h such that:
Definition
P(Θ̂l ≤ θ ≤ Θ̂h) ≥ 1 − α
⚠ Interpretation — This is critical!
WRONG: "The interval [2.1, 3.7] contains θ with 95% probability." (θ is fixed, not random!)
CORRECT: "In 95% of repeated experiments, the computed interval contains the true θ." The interval is random, not θ.
Pivot Method — General Recipe
  1. Find a pivotal quantity Q(X1,…,Xn,θ) whose distribution doesn't depend on θ
  2. Find ql, qh such that P(ql ≤ Q ≤ qh) = 1−α
  3. Rearrange to isolate θ between Θ̂l and Θ̂h

📐 CI for the Mean — Quick Reference

SituationPivot distributionCI formula
Normal pop., σ² known Z = (X̄ − μ)/(σ/√n) ~ N(0,1) X̄ ± zα/2 · σ/√n
Any pop., large n, σ² unknown Z ≈ (X̄ − μ)/(S/√n) ~ N(0,1) (CLT) X̄ ± zα/2 · S/√n
Normal pop., small n, σ² unknown T = (X̄ − μ)/(S/√n) ~ tn−1 X̄ ± tα/2, n−1 · S/√n
Upper Quantiles — zα and tα,n
zα: value where P(Z ≥ zα) = α, i.e. zα = Φ−1(1−α).
Key values: z0.025 = 1.96 (95% CI), z0.05 = 1.645 (90% CI).

Symmetry: z1−α = −zα,  t1−p,n = −tp,n
t-distribution
Bell-shaped, symmetric about 0, heavier tails than normal. E(T) = 0 (n≥2), Var(T) = n/(n−2) (n≥3). As n → ∞, t-distribution → N(0,1). Used when n is small and σ² unknown (must assume normality).

📐 CI for the Variance σ²

Assumes X1,…,Xn from N(μ, σ²). Pivot:

Chi-squared pivot
(n−1)S² / σ² ~ χ²(n−1)
CI for σ²
[(n−1)S² / χ²α/2, n−1 , (n−1)S² / χ²1−α/2, n−1]
χ² distribution
Y ~ χ²(n): defined as Z1² + ⋯ + Zn² where Zi ~ N(0,1) iid. E(Y) = n, Var(Y) = 2n. Right-skewed, positive support.
📋 Worked Example — Watermelons
10 watermelons: X̄ = 9.26, S² = 3.96. Find 95% CIs for μ and σ².
Solution
For μ (t0.025, 9 = 2.262):  9.26 ± 2.262 · √(3.96/10) = [7.84, 10.68]

For σ² (χ²0.025,9 = 19.02, χ²0.975,9 = 2.70):
[(9 × 3.96)/19.02, (9 × 3.96)/2.70] = [1.87, 13.20]
Hypothesis Testing
Setup & Definitions
  • Null hypothesis H0: default assumption (θ ∈ S0)
  • Alternative hypothesis H1: what we're trying to show (θ ∈ S1)
  • Test statistic W: a function of the data
  • Acceptance region A: values of W where we don't reject H0
  • Rejection region R: values of W where we reject H0
  • Significance level α: P(Type I error) ≤ α
Type I Error
Reject H0 when H0 is true.
P(Type I error) = P(W ∈ R | H0) ≤ α.
α = significance level. We control this.
Type II Error
Accept H0 when H1 is true.
P(Type II error) = P(W ∈ A | H1).
Harder to control — depends on the specific alternative.
⚠ Careful — "Accepting" H0
We never truly "prove" H0. When we fail to reject, it means the data is not statistically contradictory to H0 — not that H0 is confirmed true.

📐 Tests for the Mean — Three Types

Test statistic (same for all three):
Test statistic
W = (X̄ − μ0) / (σ/√n) [use S if σ unknown and n large, t-dist if small n]
TypeH0H1Rejection region R
Two-sided μ = μ0 μ ≠ μ0 |W| > zα/2
Right-sided μ ≤ μ0 μ > μ0 W > zα
Left-sided μ ≥ μ0 μ < μ0 W < −zα
Which test to use?
Large n, any distribution: z-test (CLT). Use S if σ unknown.
Small n, normal distribution, σ unknown: t-test with W ~ tn−1 under H0.
📋 Worked Example — Two-sided test, n=4
X1,X2,X3,X4 ~ N(μ, 1). Observed: 2.82, 2.71, 3.22, 2.67. Test H0: μ = 2 vs H1: μ ≠ 2 at α = 0.1.
Solution
X̄ = (2.82 + 2.71 + 3.22 + 2.67)/4 = 2.855
W = (X̄ − μ0)/(σ/√n) = (2.855 − 2)/(1/2) = 1.70
Rejection region: |W| > z0.05 = 1.645. Since 1.70 > 1.645: Reject H0.
📋 Worked Example — Right-sided test, large n
n = 100, X̄ = 21.32, S² = 27.6. Test H0: μ = 20 vs H1: μ > 20, α = 0.05.
Solution
Large n, unknown σ: use z-test with S.
W = (21.32 − 20) / √(27.6/100) = 1.32/0.525 = 2.51
z0.05 = 1.645. Since 2.51 > 1.645: Reject H0.
P-values
Definition — P-value
The p-value is the lowest significance level α for which H0 can be rejected, given the observed data. Equivalently: the probability of observing a test statistic at least as extreme as w, assuming H0 is true.

P-value formulas

Test typeP-value (observed statistic = w)
Two-sidedp = 2P(Z > |w|) = 2(1 − Φ(|w|))
Right-sidedp = P(Z > w) = 1 − Φ(w)
Left-sidedp = P(Z < w) = Φ(w)
Decision rule
Reject H0 if p < α. The p-value tells you the strength of evidence against H0. Very small p → strong evidence against H0.
📋 P-value from the previous example
Right-sided test, observed w = 2.51.
Solution
p = P(Z > 2.51) = 1 − Φ(2.51) ≈ 0.006
Since 0.006 < 0.05 = α: reject. Also would reject at α = 0.01 since 0.006 < 0.01.
Likelihood Ratio Test (LRT)

For testing between two simple hypotheses H0: θ = θ0 vs H1: θ = θ1:

Likelihood Ratio
Definition
λ(x1,…,xn) = L(x1,…,xn; θ0) / L(x1,…,xn; θ1)
Accept H0 if λ ≥ c, reject if λ < c. Choose c to achieve significance level α: P(λ < c | θ = θ0) ≤ α.
📋 Worked Example — Radar LRT
X = θ + W, W ~ N(0, 1/9). H0: θ = 0, H1: θ = 1. Level 0.05.
Solution
λ(x) = exp(9/2 · (1 − 2x)). Accept H0 when λ ≥ c ⟺ x ≤ c'.
P(X > c' | θ=0) = P(3X > 3c') = 1 − Φ(3c') = 0.05
c' = Φ−1(0.95)/3 ≈ 1.645/3 ≈ 0.548
